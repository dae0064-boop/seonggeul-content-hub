# 보험·생활보장 글 규칙 (현재 중단 상태)

**당분간 보험·생활보장 글을 쓰지 않는다.** 사용자가 직접 해제를 요청할 때까지 유효하다.
그래서 이 규칙은 상시 메모리(`memory/CLAUDE.md`)에서 이 문서로 옮겨 두었다.
보험 글을 다시 쓰기로 하면 이 문서를 읽고 시작한다.

브랜드 정체성·페르소나·출처 원칙은 `memory/CLAUDE.md` 가 정본이고 그대로 적용된다.
여기에는 **보험 글에만 해당하는 조항**만 있다.

## 글 구조 — 사례 중심 두괄식 (보험 글 버전)

| 순서 | 구성 | 주의 |
|---|---|---|
| 첫 줄 | 후킹 한 문장 | 제목·키워드와 겹치지 않게, 짧게 |
| 1 | 사례 | 익명화 + 확정 타겟과 정확히 일치 |
| 2 | 결론 | 상세설명 없이 결론만. '왜?' 궁금해 끝까지 읽게 |
| 3~4 | 정보 | 간략하게. 건강정보는 '보장과 무슨 상관인가'로 이어붙임 |
| — | 비교 | 되는 경우 / 안 되는 경우 |
| — | 체크포인트 | 독자가 자기 보험에서 확인할 것 |
| 5 | Q&A | 많이 묻는 3~5개, 답은 80%까지 (20%는 문의로 연결) |
| 6 | 정리 | 도입 사례를 긍정적 결과로 재해석 + 점검 CTA로 마무리 (= 최종 CTA) |

분량은 공백 포함 **2,000자 이상**. (생활정보 글의 2,300~2,500자 기준은 `write-post` 스킬)

**네이버 발행 양식은 글 종류와 무관하게 모든 원고가 따른다** — 제목·줄 길이·서식 표기·
이미지·front matter 규격은 `write-post` 스킬의 해당 절을 그대로 쓴다.

## 광고 심의 셀프체크 (보험 전용 조항)

금지 표현(최고·최저·제일·가장·무조건·100%·보장·손실 없음·공짜·단언컨대)은
글 종류를 가리지 않으므로 `memory/CLAUDE.md` 에 남겨 두었다. 아래는 보험 글에만 해당한다.

- 일 단위 보험료 단독 강조 금지 → 가입금액·연령·납입기간 병기
- 보장금액은 산출기준 병기
- 특약을 주계약처럼 표시 금지
- 근거 없는 타사 비교 금지
- 만기환급금·축하금은 지급 조건 함께 명시

## CTA는 '점검형' — 판매가 아니라 확인

- "가입부터 결정하기보다 현재 가지고 있는 보험부터 확인해보세요."
- "같은 보험이라도 가입 시기와 약관에 따라 달라질 수 있습니다."
- "내 보험에서는 어떻게 적용되는지 확인해보는 것이 먼저입니다."
- "현재 보장을 기준으로 부족한 부분부터 살펴보세요."

> CTA 자리마다 단락 주제에 맞춘 문구를 쓴다. 어디에나 붙는 뻔한 문구는 쓰지 않는다.
> 모든 CTA는 '성글벙글에게 상담·점검받는' 방향.
> **정보성 글에는 이 CTA를 붙이지 않는다.** 실행형으로 끝낸다.

## BRAND NO LIST — 보험 글에만 해당하는 항목

`memory/CLAUDE.md` 의 공통 금지 목록에 더해 다음을 지킨다.

1. 다른 설계사의 계약을 쉽게 잘못됐다고 평가하지 않는다
2. 기존 보험을 무조건 해지시키지 않는다
3. 상품의 장점만 이야기하지 않는다
4. 모든 SNS를 서로 다른 브랜드처럼 운영하지 않는다

> 리스크 고지 ≠ 불안 부추기기.
> '큰일 난다'가 아니라 **'내 증권을 확인해보자'**로 착지한다.

## 발행 전 필수 체크 — 10문항

- [ ] 실제 고객의 궁금증을 해결하는가?
- [ ] 결론이 명확한가?
- [ ] 어려운 내용을 쉽게 설명했는가?
- [ ] 사실과 의견이 구분되어 있는가?
- [ ] 약관·공식 근거를 확인했는가?
- [ ] 무조건 좋다/나쁘다고 표현하지 않았는가?
- [ ] 과도한 불안감을 만들고 있지는 않은가?
- [ ] 자기 상황을 생각해볼 수 있는 내용인가?
- [ ] '성글벙글'이 왜 이 얘기를 하는지 느껴지는가?
- [ ] "내 보험도 확인해보고 싶다" 들게 하는가?

> 헷갈리면 셋만 본다:
> ① 사람을 먼저 봤는가 ② 근거를 확인했는가 ③ 이해할 수 있게 설명했는가

## 파생 — 티스토리 재가공

- **문체 전면 교체**: 구어체(`~해요`) → 전문 경어체(`~합니다`). '편한데 가볍지 않은' 선은 유지.
- 두괄식 유지 + **Summary Box 필수**
- **유사문서 회피(최우선)**: 문장 구조를 재구성해 일치율을 최소화
- **내용 불변**: 보장금액·가입연령·특약명·면책/감액 기간 등 수치·명칭은 원문과 **100% 일치**
- 심의·출처·점검 CTA 유지
- 제목 3개 + 해시태그 10개
