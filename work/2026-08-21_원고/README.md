## 모바일 가독성 규칙

모바일 비중이 절대적이라 채널마다 다르게 씁니다.

| | 네이버 블로그 | 티스토리 |
|---|---|---|
| 한 줄 | **20자 내외에서 강제 줄바꿈** | 강제 줄바꿈 없음 |
| 한 문단 | 2~3줄 | 2~3문장 |
| 이유 | 모바일 화면 폭에 맞춰 시선 이동을 줄임 | 구글이 문서 구조를 읽으므로 `<br>` 남발을 피함 |

6줄 이상 이어지는 문단은 읽기 전에 부담을 줍니다. 첫 문단에서 80%가 계속 읽을지
떠날지를 정하므로 도입부는 특히 짧게 끊습니다.
