# 성글 콘텐츠 허브

건강·생활정보 분야의 **블로그 / 티스토리 / 카드뉴스** 원고를 매일 1건씩,
**중복 없이** 생산하고 진행 상태를 추적하는 저장소입니다.

## 📋 현재 작성 현황

👉 **[TRACKER.md](TRACKER.md)** 에서 확인하세요.

| 표시 | 체크박스 | 의미 |
|:---:|:---:|---|
| 🟥 | `[ ]` | 미완료 |
| 🟨 | `[~]` | 작성중 |
| 🟩 | `[x]` | 완료 |

## 📁 구조

```
├── TRACKER.md              # 작성 현황 (자동 생성 — 직접 수정하지 말 것)
├── data/
│   ├── topics.json         # 마스터 주제 풀 (채널별 40개, 총 120개)
│   └── progress.json       # 날짜별 배정·상태 기록 (중복 방지의 단일 근거)
├── content/
│   └── YYYY-MM-DD/
│       ├── blog-B###.md
│       ├── tistory-T###.md
│       └── cardnews-C###.md
└── scripts/
    └── tracker.py          # 배정 · 상태 변경 · 렌더링
```

## 🔁 중복 방지 원리

`data/progress.json` 에 한 번이라도 배정된 `topic_id` 는 **다시 선택되지 않습니다.**
`tracker.py assign` 은 주제 풀에서 아직 쓰이지 않은 첫 항목만 골라 배정하므로,
같은 주제가 두 번 나올 수 없습니다.

주제 풀이 소진되면 `assign` 이 경고를 출력합니다.
그때 `data/topics.json` 에 새 주제를 추가하면 됩니다.
(현재 재고: 채널당 40개 = **약 40일치**)

## 🛠 사용법

```bash
# 오늘 주제 배정 (중복 없이 채널별 1건)
python3 scripts/tracker.py assign

# 상태 변경
python3 scripts/tracker.py set --channel blog --status wip
python3 scripts/tracker.py set --channel blog --status done

# 현황판 다시 그리기
python3 scripts/tracker.py render

# 오늘 배정 확인
python3 scripts/tracker.py today
```

날짜를 지정하려면 각 명령에 `--date 2026-08-18` 을 붙입니다.

## ⏰ 자동 실행

매일 **오전 9시 (KST)** 에 Claude 가 자동으로 실행됩니다.

1. `assign` 으로 미사용 주제 3건 배정
2. 상태를 🟨 작성중 으로 변경
3. 블로그 · 티스토리 · 카드뉴스 원고 작성
4. 상태를 🟩 완료 로 변경 후 `render`
5. 커밋 & 푸시
6. 완료 푸시 알림 발송

## ✍️ 원고 규격

| 채널 | 분량 | 성격 |
|---|---|---|
| 블로그 | 2,000~2,500자 | 정보성 롱폼, 오해 바로잡기 중심 |
| 티스토리 | 2,000~3,000자 | 검색 유입형, 절차·비교·체크리스트 |
| 카드뉴스 | 8~9컷 | 컷별 카피 + 디자인 노트 + 해시태그 |

모든 원고 하단에는 **의료 정보 면책 문구**를 포함합니다.
