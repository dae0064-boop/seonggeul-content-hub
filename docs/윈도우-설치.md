# 윈도우 PC 설치 안내

컴퓨터를 잘 몰라도 따라 할 수 있게 썼습니다. **위에서부터 순서대로** 하시면 됩니다.
한 단계 끝날 때마다 Claude에게 "1단계 끝났어" 하고 알려주세요.

막히면 그 화면을 캡처해서 보여주시면 됩니다. 틀려도 망가지지 않습니다.

---

## 준비 · 브라우저에서 키 3개 받기

PC 설치와 상관없이 먼저 해두면 좋습니다. 인터넷만 되면 됩니다.

### 네이버 키 (무료 · 꼭 필요)

> **여기서 많이 막힙니다.** `애플리케이션 등록`부터 들어가면 목록에 `검색`이
> 보이지 않습니다. 반드시 **검색 API 페이지에서 시작**하세요.
> 그러면 `사용 API` 칸이 알아서 채워집니다.

1. `developers.naver.com` 접속 → 네이버 아이디로 로그인
2. 상단 메뉴 **Products** (또는 `서비스 API`) → **검색**
3. 그 페이지 **맨 아래**까지 내려서 **[오픈 API 이용 신청]** 버튼 클릭
4. 등록 화면이 뜹니다. 이때 **사용 API 칸에 `검색`이 이미 들어가 있습니다**
5. 애플리케이션 이름: `성글벙글자동화` (아무거나 괜찮습니다)
6. **비로그인 오픈 API 서비스 환경** → `WEB 설정` 선택
   → 웹 서비스 URL 칸에 `http://localhost` 입력
7. 등록 버튼 → **Client ID**와 **Client Secret**이 나옵니다
8. 그 화면을 **캡처해서 보관**하세요 (채팅창에는 올리지 마세요)

처음이면 중간에 **휴대폰 인증**과 **이용약관 동의**를 한 번 요구합니다. 그냥 하시면 됩니다.

**데이터랩(검색어트렌드)은 지금 안 하셔도 됩니다.** 검색 하나만 있어도 리서치는
돌아갑니다. 나중에 필요해지면 같은 방식으로 `데이터랩` 페이지에서 신청하면 됩니다.

### 유튜브 키 (무료 · 있으면 좋음)

1. `console.cloud.google.com` 접속 → 구글 로그인
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 아무거나 → 만들기
3. 검색창에 `YouTube Data API v3` 입력 → 들어가서 **사용** 클릭
4. 왼쪽 메뉴 **API 및 서비스** → **사용자 인증 정보**
5. **사용자 인증 정보 만들기** → **API 키**
6. 나온 키를 보관

### 에피파이 키 (인스타용 · 나중에 해도 됨)

1. `apify.com` → **Sign up** (구글 계정으로 가입하면 편합니다)
2. 로그인 후 왼쪽 아래 **Settings** → **API & Integrations**
3. **Personal API token** 복사해서 보관

## 1단계 · Node.js 설치 (5분)

1. `nodejs.org` 접속
2. 초록색 **LTS** 버튼 클릭 → 파일이 받아집니다
3. 받은 파일 실행 → **전부 Next / 동의 / 다음**만 누르고 끝까지
4. 설치 끝

## 2단계 · Git 설치 (5분)

1. `git-scm.com/download/win` 접속 → 자동으로 파일이 받아집니다
2. 받은 파일 실행 → **전부 Next**만 누르고 끝까지 (기본값 그대로가 정답입니다)
3. 설치 끝

## 3단계 · 터미널 열기

1. 키보드에서 **윈도우 키**를 누릅니다
2. `powershell` 이라고 칩니다
3. **Windows PowerShell**이 나오면 엔터

검은 창(또는 파란 창)이 뜹니다. 이게 터미널입니다.
앞으로 나오는 명령어는 **이 창에 붙여넣고 엔터**를 치시면 됩니다.

> 붙여넣기는 마우스 **오른쪽 클릭**입니다. Ctrl+V가 안 될 수 있습니다.

설치가 잘 됐는지 확인부터 합니다. 아래 줄을 붙여넣고 엔터:

```
node -v; git --version
```

`v22.x.x` 같은 것과 `git version 2.x.x` 같은 게 두 줄 나오면 성공입니다.
`인식할 수 없는`이라는 빨간 글씨가 나오면 PowerShell 창을 닫고 다시 여세요.

## 4단계 · Claude Code 설치

같은 창에 붙여넣고 엔터:

```
npm install -g @anthropic-ai/claude-code
```

1~2분 걸립니다. 글자가 주르륵 올라가는 건 정상입니다.

## 5단계 · 작업 폴더 받기

같은 창에 한 줄씩 붙여넣고 엔터:

```
cd $HOME\Documents
git clone https://github.com/dae0064-boop/seonggeul-content-hub
cd seonggeul-content-hub
git checkout claude/google-drive-sync-aumrmb
```

이제 `문서` 폴더 안에 `seonggeul-content-hub` 폴더가 생겼습니다.

## 6단계 · 키 넣기

1. 같은 창에 붙여넣고 엔터 — 키를 적을 파일이 만들어집니다

```
Copy-Item .env.example .env
notepad .env
```

2. 메모장이 열립니다. `=` 뒤에 아까 받아둔 키를 붙여넣으세요.

```
NAVER_CLIENT_ID=여기에붙여넣기
NAVER_CLIENT_SECRET=여기에붙여넣기
YOUTUBE_API_KEY=여기에붙여넣기
APIFY_TOKEN=여기에붙여넣기
```

- 따옴표 넣지 마세요
- `=` 앞뒤로 띄어쓰기 하지 마세요
- 아직 없는 키는 그냥 비워두세요

3. **Ctrl+S**로 저장하고 메모장을 닫습니다

## 7단계 · 제대로 됐는지 확인

같은 창에 붙여넣고 엔터:

```
node scripts/research.mjs --check
```

이런 식으로 나오면 성공입니다.

```
  ✅ 네이버 검색 — 정상
  ✅ 네이버 데이터랩 — 정상
  ✅ 유튜브 — 정상
  ✅ 에피파이 — 정상

다 됐습니다. 이제 리서치를 돌릴 수 있습니다.
```

**❌ 가 하나라도 있으면 그 줄을 그대로 복사해서 Claude에게 보여주세요.**
어디가 틀렸는지 짚어드리겠습니다.

## 자주 나오는 문제

| 증상 | 해결 |
|---|---|
| `npm`을 인식할 수 없다 | Node.js 설치 후 PowerShell을 **닫았다 다시** 여세요 |
| `git`을 인식할 수 없다 | Git 설치 후 PowerShell을 **닫았다 다시** 여세요 |
| 붙여넣기가 안 된다 | Ctrl+V 말고 **마우스 오른쪽 클릭** |
| `.env` 파일이 안 보인다 | 6단계의 `notepad .env`를 다시 실행하세요 |
| 키를 잘못 넣은 것 같다 | `notepad .env` 로 다시 열어서 고치면 됩니다 |
| 그 외 전부 | 화면을 캡처해서 Claude에게 보여주세요 |
