# 티스토리를 검색 사이트에 등록하기 (사용자용, 처음 한 번)

티스토리 손님은 대부분 **구글**에서 온다. 구글·네이버에 "내 블로그가 여기 있다"고 알려야 글을 빨리 찾아 간다.
2026-10-09 확인: 웹 검색에서 `seongdaeeyo.tistory.com` 글이 하나도 나오지 않았다 (주소로도, 글 제목으로도). 이 검색 도구는 구글이 아니라 확실하지 않지만, 아직 등록되지 않은 것으로 본다.
(처음 안내문에 주소를 `seonggeul.tistory.com` 으로 잘못 적었다 — 스크립트 도움말의 예시 주소였다. 10/9 바로잡음.)

- 내 티스토리 주소: `https://seongdaeeyo.tistory.com`
- 걸리는 시간: 구글 10분, 네이버 10분. 컴퓨터(크롬)에서 한다. 휴대폰으로는 어렵다.
- 등록해도 글이 검색에 뜨기까지 며칠~몇 주 걸린다. 바로 조회수가 오르지 않아도 정상이다.
- 다음(Daum)은 티스토리와 같은 카카오 서비스라 따로 등록하지 않아도 글을 가져간다.

화면 글자는 사이트가 바뀌면 조금 다를 수 있다. 다르게 보이면 **윈도우 키 + Shift + S** 로 화면을 캡처해 Claude 에게 붙여 주면 된다.

## 1. 구글 (가장 중요)

### 1-1. 구글 서치 콘솔에 블로그 주소 넣기

1. 크롬을 연다.
2. 주소창에 아래 주소를 붙여 넣고 Enter 를 누른다.
   ```
   https://search.google.com/search-console
   ```
3. **시작하기** 버튼을 누른다. 구글 로그인 화면이 나오면 평소 쓰는 구글 계정(Drive 와 같은 계정)으로 로그인한다.
4. "속성 유형 선택" 화면이 나온다. 왼쪽 **도메인** 말고 **오른쪽 "URL 접두어"** 칸을 쓴다.
5. 오른쪽 칸에 아래 주소를 붙여 넣는다 (칸을 마우스 오른쪽 클릭 → 붙여넣기).
   ```
   https://seongdaeeyo.tistory.com
   ```
6. 그 아래 **계속** 버튼을 누른다.
7. "소유권 확인" 창이 뜬다. 여러 방법 중 **HTML 태그** 를 눌러 펼친다.
8. `<meta name="google-site-verification" content="...">` 처럼 생긴 한 줄이 보인다. 오른쪽 **복사** 버튼을 누른다.
9. **이 창은 닫지 말고** 그대로 둔다 (마지막에 "확인"을 누르러 돌아온다).
   복사한 줄은 메모장에도 붙여 저장해 둔다 — 나중에 스킨을 바꾸면 다시 넣어야 한다.

### 1-2. 티스토리에 그 한 줄 넣기

먼저 쉬운 방법(플러그인)을 해 보고, 메뉴가 없으면 아래 "다른 방법"을 한다.

**쉬운 방법 — 플러그인**

1. 크롬에서 **새 탭**(Ctrl + T)을 연다.
2. 주소창에 붙여 넣고 Enter.
   ```
   https://seongdaeeyo.tistory.com/manage/plugins
   ```
3. 플러그인 목록 위 검색 칸에 `구글 서치` 라고 친다.
4. **구글 서치콘솔** 플러그인을 누른다 → **계정 연결하기**(또는 "연결") → 구글 계정 선택 → **허용** → **적용**.
5. 정상: 플러그인 칸에 "사용중" 또는 연결된 계정이 보인다.
6. 이 방법이 되면 1-1 의 소유권 확인이 저절로 끝나는 경우가 많다. 1-3 으로 간다.

**다른 방법 — 스킨에 직접 붙이기** (플러그인이 없거나 연결이 안 될 때)

1. 새 탭 주소창에 붙여 넣고 Enter.
   ```
   https://seongdaeeyo.tistory.com/manage/design/skin/edit
   ```
   (안 열리면: 티스토리 관리 화면 왼쪽 메뉴 **꾸미기** → **스킨 편집** → 오른쪽 위 **html 편집**)
2. 가운데 큰 글자 칸 맨 위쪽에서 `<head>` 라고 적힌 줄을 찾는다 (보통 위에서 3~5번째 줄).
3. `<head>` 줄 **맨 끝**을 마우스로 한 번 누르고 Enter 를 쳐서 새 줄을 만든다.
4. 새 줄에서 마우스 오른쪽 클릭 → 붙여넣기 (1-1 에서 복사한 한 줄).
5. 오른쪽 위 **적용** 버튼을 누른다. "저장되었습니다" 비슷한 문구가 나오면 정상.
6. **다른 줄은 지우거나 바꾸지 않는다.** 실수했으면 적용을 누르지 말고 탭을 닫았다가 다시 연다.

### 1-3. 구글로 돌아가 "확인" 누르기

1. 1-1 에서 열어 둔 구글 서치 콘솔 탭으로 돌아간다.
2. **확인** 버튼을 누른다.
3. 정상: **"소유권이 확인됨"** 이라고 나온다. **속성으로 이동** 을 누른다.
4. "소유권을 확인할 수 없음"이 나오면: 1-2 를 했는지, 적용을 눌렀는지 본다. 1분 뒤 다시 확인을 누른다. 그래도 안 되면 화면을 캡처해 Claude 에게 준다.

### 1-4. 글 목록(사이트맵) 알려 주기

1. 서치 콘솔 왼쪽 메뉴에서 **Sitemaps**(사이트맵)를 누른다.
2. "새 사이트맵 추가" 칸에 `https://seongdaeeyo.tistory.com/` 이 앞에 적혀 있고 뒤에 빈칸이 있다. 빈칸에 아래를 친다.
   ```
   sitemap.xml
   ```
3. **제출** 을 누른다.
4. 같은 칸에 이번엔 아래를 치고 다시 **제출**.
   ```
   rss
   ```
5. 정상: 아래 표에 두 줄이 생기고 상태가 **성공** 이다. "가져올 수 없음"이 나오면 하루 뒤 다시 보면 대개 성공으로 바뀐다.

## 2. 네이버 (서치어드바이저)

> 주소는 개인 도메인 **`seongdaeeyo.com`** 으로 등록한다 (2026-11-03 고침 — 티스토리 주소 글도 이 주소를 정본으로 가리킨다).

네이버 검색 결과에는 네이버 블로그가 먼저 나오지만, 등록해 두면 티스토리 글도 "웹문서" 칸에 뜰 수 있다.

### 2-1. 사이트 등록

1. 크롬 새 탭 주소창에 붙여 넣고 Enter.
   ```
   https://searchadvisor.naver.com
   ```
2. 오른쪽 위 **로그인** → 네이버 아이디로 로그인 (블로그 쓰는 그 아이디).
3. 위쪽 **웹마스터 도구** 를 누른다. 처음이면 약관 동의 화면이 나온다 → 동의.
4. "사이트 등록" 칸에 아래 주소를 붙여 넣고 오른쪽 **→** (화살표) 버튼.
   ```
   https://seongdaeeyo.com
   ```
5. "사이트 소유확인" 화면에서 **HTML 태그** 를 고른다.
6. `<meta name="naver-site-verification" content="...">` 한 줄이 보인다. 그 줄을 마우스로 끌어 선택하고 Ctrl + C 로 복사한다.
   메모장에도 붙여 저장해 둔다.

### 2-2. 티스토리에 붙이기

**쉬운 방법 먼저**: 티스토리 관리 → **플러그인** → 검색 칸에 `메타 태그` → **메타 태그 등록** 플러그인 → 6번에서 복사한 줄을 붙여 넣고 **적용**. 이 플러그인이 없을 때만 아래처럼 스킨에 붙인다.

1-2 의 **"다른 방법 — 스킨에 직접 붙이기"** 를 그대로 한다. 이번엔 네이버 줄을 붙인다.
(구글 줄을 이미 붙였으면 그 줄 **바로 아래**에 새 줄을 만들어 붙인다. 구글 줄은 지우지 않는다.)
적용을 누른다.

### 2-3. 네이버로 돌아가 확인

1. 서치어드바이저 탭으로 돌아가 **소유확인** 버튼을 누른다.
2. 정상: "소유확인이 완료되었습니다". 사이트 목록에 `https://seongdaeeyo.com` 이 생긴다.
3. 목록의 주소를 누른다 → 왼쪽 메뉴 **요청** → **사이트맵 제출** → 칸에 아래를 붙여 넣고 **확인**.
   ```
   https://seongdaeeyo.com/sitemap.xml
   ```
4. 같은 **요청** 메뉴의 **RSS 제출** → 아래를 붙여 넣고 **확인**.
   ```
   https://seongdaeeyo.com/rss
   ```

## 3. 다시 할 것 (2026-11-03) — 사이트맵 다시 제출 + 빙 등록

> **주소는 `seongdaeeyo.com`** — 블로그에 개인 도메인이 연결돼 있고, 티스토리 주소 글도 이 주소를 정본(canonical)으로 가리킨다. 서치 콘솔·빙 모두 이 주소로 본다 (11/3 처음 안내에 tistory 주소를 잘못 적어 바로잡음).

왜: 구글이 사이트맵을 **10/23 뒤로 다시 읽지 않았다**. 그사이 글 주소 모양이 `/숫자` 에서 `/entry/제목` 으로 바뀌었다.
다시 제출하면 구글이 새 주소 목록을 읽어 간다. 빙은 구글에 등록한 것을 그대로 가져올 수 있어 5분이면 끝난다
(빙 검색과 ChatGPT 검색이 빙 목록을 쓴다). 둘 다 컴퓨터 크롬에서 한다. 합쳐서 10분쯤.

### 3-1. 구글 사이트맵 다시 제출 (5분)

1. 크롬을 연다.
2. 주소창에 아래 주소를 붙여 넣고(마우스 오른쪽 클릭 → 붙여넣기) Enter.
   ```
   https://search.google.com/search-console/sitemaps?resource_id=https%3A%2F%2Fseongdaeeyo.com%2F
   ```
3. 정상: 화면 위에 **Sitemaps** 라고 쓰여 있고, 아래 "제출된 사이트맵" 표에 `/sitemap.xml` 줄이 보인다.
   - 다른 주소가 보이면: 화면 왼쪽 위 주소 칸을 눌러 **`https://seongdaeeyo.com/`** 을 고른다 (블로그에 연결한 개인 도메인. `seongdaeeyo.tistory.com` 이 아니다).
   - "속성에 액세스할 수 없음"이 나오면: 오른쪽 위 동그란 사진을 눌러 Drive 와 같은 구글 계정인지 본다.
4. 위쪽 **"새 사이트맵 추가"** 칸의 빈칸을 눌러 아래를 친다.
   ```
   sitemap.xml
   ```
5. 칸 오른쪽 **제출** 을 누른다.
6. 정상: "사이트맵이 제출되었습니다" 창이 뜬다 → **확인**. 표의 `/sitemap.xml` 줄 **"마지막으로 읽은 날짜"가 오늘(11월 날짜)** 로 바뀌고 상태가 **성공** 이다.
   - "가져올 수 없음"이면: 그대로 두고 내일 다시 이 화면을 연다. 내일도 같으면 화면 캡처(윈도우 키 + Shift + S)를 Claude 에게 붙여 준다.
7. 같은 칸에 `rss` 를 치고 **제출** 을 한 번 더 누른다 (이미 있으면 "이미 제출됨" 같은 말이 나와도 괜찮다).

### 3-2. 빙 웹마스터 도구 등록 (5분)

1. 크롬 새 탭(Ctrl + T) 주소창에 붙여 넣고 Enter.
   ```
   https://www.bing.com/webmasters
   ```
2. **로그인**(또는 "Sign in") 버튼을 누른다 → 세 가지 중 **Google** 을 고른다 → 위 3-1 과 같은 구글 계정을 고른다 → **허용**(또는 "계속").
3. "사이트 추가" 화면이 나온다. 두 칸 중 **"Google Search Console에서 가져오기"**(영어면 "Import your sites from GSC") 쪽 **가져오기**("Import") 를 누른다.
4. 구글 계정 고르기 창이 다시 뜨면 같은 계정 → **허용**.
5. 사이트 목록에 `https://seongdaeeyo.com/` 가 보인다. 앞 네모에 체크 → **가져오기**("Import").
   - 목록이 비어 있으면: 2단계에서 다른 구글 계정을 고른 것이다. 오른쪽 위 계정 사진 → 로그아웃 → 2단계부터 다시.
6. 정상: "사이트를 가져왔습니다"(영어 "Sites imported") 같은 말과 함께 대시보드가 열린다. 사이트맵도 같이 들어온다 — 따로 넣을 것은 없다.
7. 왼쪽 메뉴 **사이트맵**("Sitemaps") 을 눌러 `sitemap.xml` 줄이 보이면 끝. 안 보이면 오른쪽 위 **사이트맵 제출**("Submit sitemap") → `https://seongdaeeyo.com/sitemap.xml` 붙여 넣기 → **제출**.

빙은 처음 며칠 "처리 중"으로 보이는 게 정상이다. 숫자가 바로 오르지 않아도 된다.

## 4. 애드센스용 공지 3개 올리기 (2026-11-03, 15분, 처음 한 번)

애드센스 심사는 "누가 운영하는지(소개), 방문자 정보를 어떻게 다루는지(개인정보처리방침), 연락할 길(문의)"이 있는지 본다.
글은 Claude 가 써 두었다 — 저장소 `content/tistory-pages/` 의 `about.txt`·`privacy.txt`·`contact.txt`. 사용자는 붙여 넣기만 한다.

1. 크롬 새 탭 주소창에 붙여 넣고 Enter.
   ```
   https://seongdaeeyo.tistory.com/manage
   ```
2. 왼쪽 메뉴 **콘텐츠** → **공지사항**(또는 "공지") 을 누른다.
3. 오른쪽 위 **공지 쓰기**(또는 "새 공지") 를 누른다.
   - 공지 메뉴가 안 보이면: 화면 캡처(윈도우 키 + Shift + S)를 Claude 에게 붙여 준다.
4. 제목 칸에 `성글벙글 블로그 소개` 라고 친다.
5. Claude 가 대화창에 보내 준 소개 글을 마우스로 끌어 선택 → Ctrl + C → 본문 칸을 누르고 Ctrl + V.
6. 오른쪽 아래 **공개 발행**(또는 "완료" → "공개") 을 누른다.
7. 3~6번을 두 번 더 한다 — 제목 `개인정보처리방침`(privacy), `문의하기`(contact).
8. 정상: 블로그 첫 화면 위쪽이나 메뉴에 공지 3개가 보인다.

다 하면 Claude 에게 "공지 3개 올렸어" 라고만 말한다.
