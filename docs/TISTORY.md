# 티스토리 자동화

네이버 블로그와 **다른 게임**이다 (`standards/발행-운영기준.md`). 같은 글을 양쪽에 올리지 않는다.
**네이버와 다른 내용·다른 제목**으로 쓴다 (2026-10-02 사용자 지시 — 같으면 유사문서에 걸린다).
네이버 글을 고쳐 쓰지 않고, 같은 묶음의 **다른 메인 키워드**를 잡는다 (`memory/CLAUDE.md` [8]).
예: 네이버 "등산 스틱 길이" → 티스토리 "하산 무릎".

## 지금 되는 것 / 아직 안 되는 것

| 단계 | 상태 |
|---|---|
| 원고 형식 · 변환(`build-tistory.mjs`) | 됨 |
| 검사기(`lint-tistory.mjs`) — 구조·경어체·네이버 글과 키워드·제목·본문 겹침 | 됨, PR 검사에도 걸림 |
| 임시저장(`publish-tistory.mjs --save-draft`) | 만들었음. **실제 티스토리 화면에서는 아직 안 돌려 봤다** |
| 발행 패널 기록(`--dry-run`) | 만들었음. 예약발행을 만들 자료를 남긴다 |
| 예약발행(`--reserve`) | **없다.** `--dry-run` 결과를 보고 만든다 |
| 사진 넣기 | **없다.** `[이미지 N]` 자리를 글자로 남긴다 |
| 매일 자동 실행 | **걸지 않았다.** 아래 순서를 지킨 다음에 건다 |

클라우드 세션에서는 `tistory.com`·`kakao.com` 이 막혀 있다 (`connect_rejected`). 실제 실행은 PC 에서만 된다.

## 처음 켜는 순서

스레드 자동화 때 교훈대로, **확인하기 전에 자동 실행부터 걸지 않는다.**

1. `launchers\chrome-login.cmd` — 자동화용 크롬이 뜨면 두 번째 탭에서 티스토리(카카오)에 로그인한다.
   네이버와 같은 크롬·같은 프로필을 쓴다.
2. `launchers\tistory-test.cmd` 더블클릭 — 원고를 임시저장하고, '완료' 패널을 열어 화면을 기록한 뒤
   **발행하지 않고** 닫는다. 오늘 원고가 없으면 가장 최근 날짜 원고로 한다.
   처음 한 번 블로그 이름(`<이름>.tistory.com` 의 앞부분)을 묻는다.
   평소 임시저장만 할 때는 `launchers\tistory-day.cmd`.
3. 티스토리 관리 화면 → 임시저장 목록에서 글을 열어 본다 — 제목·표·요약 상자·태그·카테고리가 맞는지.
4. 실행 기록과 스크린샷이 Drive `ClaudeWorkspace/run-logs/` 에 올라간다. Claude 에게 확인을 부탁하면
   그 기록으로 선택자를 고치고 예약발행을 붙인다.
5. 며칠 임시저장이 문제없이 돌면 그때 `auto-day.cmd` 에 티스토리 단계를 넣는다.

## 원고

`content/tistory/<날짜>-<슬러그>.md` 가 정본이다. `.json`(스크립트 입력)·`.html`(붙여넣기용)은 생성물이니 고치지 않는다.

```bash
node scripts/lint-tistory.mjs content/tistory/<원고>.md     # 통과해야 올린다
node scripts/build-tistory.mjs content/tistory/<원고>.md    # .json · .html 생성
```

앞머리:

```
---
title: 하산 무릎 부담 줄이는 법: 내려오는 속도·보폭·발 딛는 순서
main_keyword: 하산 무릎
sub_keywords: 보폭, 속도, 휴식
type: 가이드                      ← 롱폼(2,500자+) / 가이드 / 비교 (1,500자+, 공백 제외)
category: 생활정보
tags: 태그1, 태그2, …             ← 10개 이하
source_post: 2026-10-02-deungsan-stick   ← 같은 묶음의 네이버 글 (선택. 고쳐 쓰라는 뜻이 아니다)
---
```

본문은 마크다운 일부만 쓴다: `## / ###` 제목, 문단, `-`·`1.` 목록, `- [ ]` 체크리스트, 표, `>` 인용,
`**굵게**`, `[글자](https://…)`, `[이미지 N] 대체텍스트`, 글 맨 앞 `:::summary … :::` 요약 상자.

검사기가 잡는 것:

| 항목 | 기준 |
|---|---|
| 분량 | 공백 제외 1,500자+ (롱폼 2,500자+) |
| 구조 | H2 3개+, 표 1개+, 요약 상자, 출처·기준일 |
| 줄바꿈 | 문단 안 줄바꿈 금지 (네이버식 강제 개행 X). 문단 5문장 초과 금지, 3문장 초과는 알림 |
| 문체 | 평서문 중 `~요.` 10% 이하 — `~합니다` 체 |
| 네이버 표기 | `[빨간글씨]`, `인용구(소제목)`, 고정 인사말, 이웃추가 문구가 남아 있으면 불통과 |
| 키워드 | 네이버 글의 메인 키워드와 같으면 불통과. 제목에 네이버 메인 키워드가 그대로 들어가도 불통과 |
| 제목 | 네이버 제목과 유사도(글자 2개 조각) 40% 미만 (25% 이상이면 알림) |
| 본문 | 네이버 글과 10글자 조각 겹침 15% 미만 (8% 이상이면 알림) |
| 키워드 | 제목에 메인 키워드, 본문 4회+ (구글은 반복 횟수를 세지 않는다) |

비교 대상은 `source_post` 하나가 아니라 `content/posts/` 의 네이버 글 전부다.

## 발행 스크립트

```bash
node scripts/publish-tistory.mjs --post content/tistory/<원고>.json --save-draft --dump
```

- 블로그는 `--blog <이름>` 또는 환경변수 `TISTORY_BLOG`.
- 본문은 한 줄씩 치지 않고 HTML 을 통째로 넣는다 — 기본 에디터(TinyMCE)에 먼저, 안 되면 HTML 모드에.
  넣은 뒤 **H2 개수·표 개수·글자 수를 다시 읽어 맞춰 보고, 다르면 저장하지 않는다.**
- 저장 버튼 글자에 `발행·완료·공개` 가 보이면 멈춘다.
- `--publish-now` 는 '공개'가 선택된 것을 확인한 뒤에만 누른다. 사람이 그 자리에서 붙일 때만 쓴다.
- attach 한 크롬은 끄지 않는다. 탭도 닫지 않는다.
- 자동화가 막히면 `content/tistory/<원고>.html` 을 에디터 HTML 모드에 붙여넣으면 된다.

## 하루 편성

`standards/발행-운영기준.md` 기준은 하루 3편(롱폼·가이드·비교)이지만, **새 블로그는 1주차 1편 → 2주차 2편 →
3주차부터 3편**으로 늘린다. 애드센스도 단기 양산을 거절 사유로 본다.
