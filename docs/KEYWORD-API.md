# 네이버 검색 키 고치기 (경쟁 확인용) — 사용자용, 10분

**왜 필요한가요?** 아침 자동 실행이 키워드 검색량을 조회할 때, 그 말로 네이버 블로그 검색 상위 10편이
얼마나 오래된 글인지도 같이 보게 했습니다 (2026-10-19). 오래된 글이 많으면 우리 새 글이 들어갈 틈이 있고,
최근 글로 꽉 차 있으면 최적화 블로그와 경쟁이 세다는 뜻입니다. 그런데 지금 이 조회가
`검색 API 401` 로 막혀 있습니다 — 키가 틀렸거나, 네이버 개발자 앱에 '검색' 기능이 빠져 있다는 뜻입니다.
돈은 들지 않습니다. **발행 PC 두 대(사무실 PC·노트북) 모두에 같은 키를 넣어야** 합니다.

## 1. 키 확인하기 (사무실 PC 나 노트북, 아무 쪽에서 한 번)

1. 크롬을 열고 주소창에 `developers.naver.com/apps` 를 치고 Enter.
2. 네이버 아이디로 로그인합니다.
3. **내 애플리케이션** 목록이 보입니다.
   - 목록에 앱(예: `성글벙글자동화`)이 **있으면** → 그 이름을 누르고 아래 2번으로.
   - 목록이 **비어 있으면** → 아래 3번(새로 만들기)으로.

## 2. 있는 앱에 '검색' 넣기

1. 앱 이름을 누르면 위쪽에 탭이 보입니다. **API 설정** 탭을 누릅니다.
2. **사용 API** 칸에 `검색` 이 있는지 봅니다.
   - 없으면: 칸 옆 목록에서 `검색` 을 골라 추가 → 화면 맨 아래 **수정** 버튼.
3. **개요** 탭으로 돌아가 **Client ID** 와 **Client Secret**(보기 버튼)을 확인합니다. → 4번으로.

## 3. 앱이 없으면 새로 만들기

1. 주소창에 `developers.naver.com/products/service-api/search/search.md` 를 치고 Enter.
2. 화면 맨 아래 **오픈 API 이용 신청** 버튼을 누릅니다. (이 길로 들어가야 '검색' 이 미리 채워집니다.)
3. 애플리케이션 이름: `성글벙글자동화`
4. **비로그인 오픈 API 서비스 환경** → `WEB 설정` → URL 칸에 `http://localhost`
5. **등록하기** → **Client ID** 와 **Client Secret** 이 보입니다. 이 화면을 열어 둡니다.

## 4. PC 에 키 넣기 (사무실 PC·노트북 각각)

1. 키보드 윈도우 키를 누르고 `메모장` 이라고 친 뒤 Enter — 메모장이 열립니다.
2. 메모장 메뉴 **파일 → 열기** → 위쪽 주소칸에 아래를 붙여 넣고(마우스 오른쪽 → 붙여넣기) Enter:
   - 사무실 PC: `C:\Users\dae00\seonggeul-content-hub`
   - 노트북: `C:\Users\user\Documents\seonggeul-content-hub`
3. 오른쪽 아래 `텍스트 문서(*.txt)` 를 **모든 파일(*.*)** 로 바꾸면 `.env` 가 보입니다. 열기.
4. `NAVER_CLIENT_ID=` 와 `NAVER_CLIENT_SECRET=` 줄을 찾아 `=` 뒤를 새 값으로 바꿉니다.
   - 따옴표·띄어쓰기 없이. 줄이 없으면 맨 아래에 두 줄을 새로 적습니다.
   ```
   NAVER_CLIENT_ID=복사한ClientID
   NAVER_CLIENT_SECRET=복사한ClientSecret
   ```
5. **Ctrl + S** 로 저장하고 닫습니다. 끝 — 다음 날 아침 자동 실행부터 조회됩니다.

## 잘 됐는지

다음 날 아침 확인(10:47)이 알려 드립니다. 키워드 결과에 `◆ 상위 10편: 1년 넘은 글 …` 줄이 생기면 성공,
`검색 API 401` 이 그대로면 Client ID·Secret 을 다시 복사해 넣습니다. 모르겠으면 메모장 화면을 **가리고**
(키는 보이지 않게) 네이버 개발자 화면만 캡처(윈도우 키 + Shift + S)해서 보여 주세요. **키 값은 채팅에 올리지 않습니다.**
