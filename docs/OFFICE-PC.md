# 사무실 PC 에서 이어서 작업하기

노트북에서 하던 작업을 사무실 PC 에서 그대로 이어 갈 때 이 순서대로 한다 (2026-10-08 사용자 요청).
사무실 PC 저장소 폴더: `C:\Users\dae00\seonggeul-content-hub`

## 시작할 때 (5분)

1. **노트북 정리** — 노트북 화면 오른쪽 아래 Google Drive 아이콘(구름 모양)을 눌러 **"최신 상태"** 가 보이면 노트북을 덮는다.
   두 PC 에서 동시에 작업하지 않는다.
2. **사무실 PC 를 켜고 윈도우에 로그인한다.**
   - 오전(05~15시)이고 오늘 예약 안 된 글이 남아 있으면 검은 창이 저절로 떠서 예약을 시작한다. 그대로 두면 된다.
   - 오늘 글이 다 예약돼 있으면 아무 창도 뜨지 않는다. 정상이다.
3. 화면 오른쪽 아래 Google Drive 아이콘이 **"최신 상태"** 가 될 때까지 1~2분 기다린다.
4. 파일 탐색기(윈도우 키 + E)를 열고 주소창에 아래를 붙여 넣고 Enter (붙여 넣기는 마우스 오른쪽 클릭 → 붙여넣기).
   ```
   C:\Users\dae00\seonggeul-content-hub\launchers
   ```
5. **`sync.cmd`** 를 더블클릭한다. 1~2분 걸린다.
   - 정상: 맨 아래에 **"최신 상태예요. 이제 Claude 에게 "이어서 진행해줘" 라고 하면 됩니다."** 가 보인다.
   - `[3/4]` 줄에 **"켜져 있어요 (발행 담당 PC)"** 가 보이면 내일 아침 자동 예약도 이 PC 가 할 수 있다.
     **"꺼져 있어요"** 면 같은 폴더의 `auto-setup.cmd` 를 한 번 더블클릭한다.
   - "받아오지 못했어요" / "main 으로 바꾸지 못했어요" 가 보이면 창을 캡처(윈도우 키 + Shift + S)해서 Claude 에게 붙여 준다.
   - 아무 키나 눌러 창을 닫는다.
6. **Claude 앱을 열고 새 대화**에서 이 저장소(seonggeul-content-hub)를 고른 뒤 **"이어서 진행해줘"** 라고 쓴다.
   Claude 가 GitHub 최신 내용과 `docs/STATUS.md` 를 읽고 남은 일을 바로 한다. 지난 대화를 기억하지 못해도 STATUS 에 다 적혀 있다.

## 작업 중

- 원고·규칙 고치기, 결과 확인 같은 일은 Claude 에게 말로 하면 된다. 클라우드 Claude 는 네이버에 직접 접속하지 못한다 —
  실제 예약은 PC 의 `auto-day.cmd` 가 한다.
- "로그인이 풀렸다"는 알림이 오면 `launchers\chrome-login.cmd` 를 더블클릭한다. 풀린 곳만 로그인 창이 열린다.
- 내일 아침 PC 를 못 켤 것 같으면 퇴근 전에 `launchers\reserve-tomorrow.cmd` 를 더블클릭한다 (내일 네이버 글을 오늘 밤 예약).

## 끝낼 때

1. Claude 에게 **"STATUS 갱신하고 마무리해줘"** 라고 한다 (Claude 가 진행 상황을 적어 GitHub 에 올린다).
2. Google Drive 아이콘이 **"최신 상태"** 가 된 뒤 PC 를 끈다 (또는 절전).
3. 다음 날 아침에는 노트북이든 사무실 PC 든 하나만 켜면 그 PC 가 예약발행을 한다.
