### GOMS 광고심의 등록 자동화 — ✅ 작동 (10/5 오후 30편까지 등록)
- 사용자: "광고심의를 매번 체크하고 파일을 올리는데 너무 힘들어". 회사(글로벌금융판매) 업무 시스템 GOMS(`globalgoms.co.kr`)에

- **실행**: PC 에서 `launchers/goms-register.cmd` 더블클릭 → "몇 편부터?" / "몇 편까지?" 입력 → 한 편에 약 1분.
  등록한 편은 Drive `ClaudeWorkspace/goms-done/스레드 N편.done`, 결과는 Drive `run-logs/goms-register-<날짜_시각>-<PC>/`(result.txt·progress.txt).
  `launchers/goms-test.cmd` 는 등록 직전까지만 하는 시험용.
- **진행 순서 (`scripts/goms-ad.mjs`)**: 로그인 화면이면 LOGIN 클릭(크롬 자동 채움, 비밀번호는 넣지도 저장하지도 않음) → 업무 → 광고심의 → 목록의 "등록" →
  접수자와 동일 / 광고제목 `스레드 N편` / 신청구분 신규 / 광고구분 업무광고 / 광고방법 SNS / 경품여부 아니오(필수칸) / 파일추가 `스레드 N편.docx`(Drive `ClaudeWorkspace/보험글/`)

- **GOMS 화면에서 알게 된 것 (고칠 때 참고)**: 신청서는 목록 위에 뜨는 창이고 목록의 "등록"·검색칸이 그대로 보인다(신청서 영역에만 동작).
  동그라미·네모 칸은 `span.radio`(안 고름)/`svg`(고름), 네모는 `.check-box-container`. 칸 이름과 입력칸이 한 줄에 같이 있다.
  탭은 Vuetify `role=tab`, 광고구분을 고르면 탭 이름이 "업무광고 심의점검표"로 바뀐다. 점검표는 해당없음·적합·미흡·부적합 4열 × 30줄 표로,
  보이는 줄만 그려지고 자체 스크롤바(div.scroll-bar)라 **마우스 휠**로만 내려간다. 빠진 줄은 등록 뒤 빨간 줄(`tr.notice-emergency`)로 표시된다.
  확인 창("알림")은 신청서 영역 안에 그려진다.
