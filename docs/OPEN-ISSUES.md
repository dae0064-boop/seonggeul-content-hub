# 미해결 과제

2026-09-13 규칙서 점검에서 나왔으나 판단이 필요해 손대지 않은 것들.
고칠 때 이 문서도 함께 지운다.

## 1. 보험 전제 규칙과 "보험 글 중단" 지시가 겹쳐 있다

`memory/CLAUDE.md` 의 `[0]` `[2]` `[6]` `[7]` `[9]` 는 보험 영업을 전제로 쓰였다.
그런데 문서 맨 위 지시는 보험 글을 당분간 쓰지 않는다고 못박고 있다.

`[10]` 이 "정보성 글에는 이건 빼고 저건 지킨다"로 예외를 정리해 두었지만,
읽는 순서상 보험 규칙을 먼저 만나고 뒤에서 뒤집는 구조라 헷갈린다.
특히 이런 항목들이 정보성 글에는 그대로 적용되지 않는다:

- `[2]` 구조표의 "건강정보는 '보장과 무슨 상관인가'로 이어붙임",
  "독자가 자기 보험에서 확인할 것", "점검 CTA로 마무리"
- `[9]` 10문항의 "약관·공식 근거를 확인했는가",
  "'내 보험도 확인해보고 싶다' 들게 하는가", "실제 고객의 궁금증"

**정할 것**: 보험 글 재개 계획이 있는가.
- 없다면 → 보험 전용 조항을 별도 문서로 떼어내고 본문은 정보성 기준으로 다시 쓴다.
- 있다면 → 지금 구조를 두되 `[2]` `[9]` 에 정보성 버전을 나란히 적는다.

## 2. `scripts/check_post.py` 가 현재 원고 형식으로는 돌지 않는다

한글 앞머리(`제목:` `타겟:` `목적:`)를 전제로 쓰였는데 실제 원고는 영문 키
(`title:` `main_keyword:`)를 쓴다. 분량 세는 법도 `lint-post.mjs` 와 달라
같은 원고를 2,310자 / 2,854자로 다르게 센다.

지우지 않은 이유는 `lint-post.mjs` 에 없는 검사를 갖고 있기 때문이다 —
광고 심의 금지어, 출처 URL 유무, 이미지 장수, Q&A 개수.

**할 일**: 앞머리 파서를 영문 키로 맞추고, 분량 계산을 `lint-post.mjs` 와
같게(줄바꿈 제외) 바꾼다. 그 전까지 발행 판단은 `lint-post.mjs` 로만 한다.

## 3. `유형: 구조설명` 앞머리 필드가 사라졌다

`check_post.py` 는 이 값이 `구조설명` 이면 출처 URL 요구를 건너뛴다.
그런데 실제 원고 앞머리에는 이 필드가 없어서 항상 출처를 요구한다.
2번을 고칠 때 같이 정한다 — 이 구분을 유지할지, 없앨지.
