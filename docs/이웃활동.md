# 하루 10분 이웃 활동 (사용자용)

2026-10-16 사용자가 하기로 함. 목적: 우리 새 글이 발행 첫 몇 시간 안에 공감·댓글을 받게 해 홈판에 올라가게 한다.
자동 프로그램(자동 공감·댓글·이웃 추가)은 쓰지 않는다 — 네이버가 어뷰징으로 보고 블로그 전체 노출을 낮출 수 있다.

## 언제

- **하루 한 번, 10분.** 점심(12시 글 나간 뒤)이나 밤 9시 글 나간 뒤가 좋다 — 이웃이 우리 블로그에 왔을 때 막 나간 새 글을 본다.
- 못 한 날은 그냥 넘어간다. 몰아서 하루 30곳 하는 것보다 매일 5곳이 낫다.

## 순서 (휴대폰)

1. 휴대폰에서 **네이버 블로그 앱**(초록색 'b' 아이콘)을 연다.
2. 위쪽 돋보기(검색)를 누르고 우리 블로그 주제 말을 하나 친다.
   예: `김장 준비` `세탁조 청소` `결로 곰팡이` `제철 꼬막` `실비 청구`
3. 결과에서 **'블로그'** 탭을 누르고, 위에 **'최신순'** 이 있으면 누른다.
4. 아래 셋에 맞는 글을 하나 고른다.
   - 개인이 쓴 블로그 (업체·체험단 광고 글은 건너뛴다 — 제목에 '협찬', 업체명이 크게 있으면 광고)
   - 1주일 안에 쓴 글
   - 살림·요리·제철·생활정보·보험 정보처럼 우리와 비슷한 주제
5. 글을 **끝까지 읽는다** (1분 이상). 훑고 바로 공감만 누르면 효과가 없고, 기계처럼 보인다.
6. 글 맨 아래 **하트(공감)** 를 누른다.
7. 하트 옆 **말풍선(댓글)** 을 눌러 1~2문장을 쓴다. **글 내용 한 가지를 짚어서** 쓴다.
   - "소금물에 30분 담그는 건 처음 알았어요. 이번 주말에 해 볼게요"
   - "저희 집도 베란다 결로가 심한데 신문지 방법은 몰랐네요"
   - "사진으로 보니 손질 순서가 한눈에 들어와요. 저장해 둘게요"
8. 오른쪽 아래 **'등록'** 을 누른다. 댓글이 글 아래에 보이면 끝.
9. 이 블로그가 마음에 들면 블로그 이름을 눌러 들어가 **'이웃추가'** → **'서로이웃'** 을 고르고,
   메시지 칸에 "살림 정보 자주 보러 올게요" 처럼 한 줄 쓴 뒤 **'다음'** → **'완료'**.
10. 2~9를 반복해 **하루 5~10곳**. 서로이웃 신청은 하루 3~5곳까지만.

## 하지 않을 것

- "좋은 글 잘 보고 갑니다~ 서이추해요" 같은 똑같은 문장 복사 — 네이버가 스팸으로 본다.
- 댓글에 우리 블로그 주소·글 제목 붙이기.
- 하루 수십 곳 몰아서 하기, 읽지 않고 공감만 누르기.

## 우리 블로그에 댓글이 달리면

- **그날 안에 답글을 단다.** 우리 블로그 앱 아래 종 모양(알림)을 누르면 새 댓글이 보인다.
- 답글을 단 분의 블로그에 한 번 가서 위 5~8번을 해 주면 이웃이 된다.

## 잘 되고 있는지

아침 확인(월요일)이 우리 글 공감·댓글 평균을 본다. 지금 공감 평균 2·댓글 0 → 2주 뒤(10/30) 목표 공감 5·댓글 1.
오늘 쓴 글이 발행 당일 조회 상위 20에 드는지도 같이 본다.

화면이 다르게 보이면 캡처(휴대폰은 전원 + 소리 줄이기 버튼 동시에)해서 대화에 붙여 주세요.
