## 처음 한 번만 (사람이 할 일)

인스타그램은 **연결 키**가 있어야 프로그램이 대신 올릴 수 있다. 키는 Meta(인스타그램 회사) 개발자 화면에서 만든다. 20~30분 걸린다.
화면 이름이 아래와 조금 다르면 비슷한 이름을 누르고, 모르겠으면 화면 캡처(윈도우 키 + Shift + S)를 Claude 에게 붙여 주세요.

### 1단계 — 인스타 계정을 '프로페셔널 계정'으로 (휴대폰, 3분)

1. 휴대폰에서 인스타그램 앱을 열고 「친근한 설계사」 계정으로 들어간다.
2. 오른쪽 아래 내 프로필 사진 → 오른쪽 위 줄 세 개(☰).
3. **계정 유형 및 도구** → **프로페셔널 계정으로 전환**.
4. 종류는 **비즈니스** 를 고른다 (카테고리는 "금융 서비스" 나 "보험 설계사" 비슷한 것).
5. 끝나면 프로필 아래에 "프로페셔널 대시보드" 가 보이면 정상이다.
   - 이미 프로페셔널 계정이면 이 단계는 건너뛴다.

### 2단계 — Meta 개발자 앱 만들기 (PC, 10분)

1. 크롬에서 **developers.facebook.com** 을 연다 → 오른쪽 위 **로그인** (페이스북 계정으로. 스레드 키를 만들 때 쓴 계정이면 된다).
2. 오른쪽 위 **내 앱** → **앱 만들기**.
3. "이용 사례" 목록에서 **Instagram 에서 메시지 및 콘텐츠 관리** (영어로는 *Manage messaging & content on Instagram*) 를 고르고 **다음**.
4. 앱 이름에 `seonggeul-insta` 처럼 아무 이름 → **앱 만들기** (비밀번호를 한 번 더 물을 수 있다).
5. 앱 화면 왼쪽 **이용 사례** → 방금 고른 Instagram 칸의 **맞춤 설정**.
6. **Instagram 로그인을 통한 API 설정** 화면이 열리면 정상이다.

### 3단계 — 연결 키 만들기 (PC, 5분)

1. 그 화면의 **2. 액세스 토큰 생성** 칸에서 **계정 추가** 를 누른다.
2. 새 창에서 「친근한 설계사」 인스타 계정으로 로그인 → 권한 화면에서 **허용**.
   - "테스터" 초대를 받으라고 나오면: 휴대폰 인스타 → ☰ → **웹사이트 권한** → **앱 및 웹사이트** → **테스터 초대** → 수락, 그다음 다시 1번.
3. 목록에 계정이 생기면 그 줄의 **토큰 생성** 을 누른다.
4. 긴 글자(IG 로 시작)가 나오면 **복사** → 메모장에 붙여 둔다. 이 글자는 비밀번호처럼 다룬다 — 카톡·메일로 보내지 않는다.
5. 권한 목록에 `instagram_business_basic`, `instagram_business_content_publish` 가 들어 있어야 한다 (기본으로 들어 있다).

### 4단계 — PC 에 키 넣기 (사무실 PC, 1분)

1. 파일 탐색기에서 저장소 폴더 `C:\Users\dae00\seonggeul-content-hub\launchers` 를 연다.
2. **insta-key.cmd** 를 더블클릭한다.
3. "키" 칸에 메모장의 글자를 붙여 넣는다 (마우스 오른쪽 클릭). 화면에는 `*` 로만 보인다 → **Enter**.
4. `[OK] 키가 정상이에요. 연결된 계정: @… (BUSINESS)` 가 보이면 끝. 창을 닫는다.
   - `[X] 인스타그램이 이 키를 받아 주지 않았어요` → 3단계를 다시 해서 새 키로.
   - `계정 종류가 PERSONAL 예요` → 1단계를 먼저.
5. 노트북에서도 올리려면 노트북에서 1~4번을 한 번 더 (같은 키를 붙여 넣어도 된다). 지금은 사무실 PC 만이면 충분하다.
