성글벙글 실행기 — 평소에는 아무것도 누르지 않아도 돼요
=====================================================

아침에 PC 를 켜거나 잠금을 풀면 오늘 글 예약발행이 저절로 시작돼요.
(2026-11-13 정리 — 안 쓰는 실행기를 모두 지우고 11개만 남겼어요. 지운 것은 Claude 가 언제든 되살려요.)


■ 가끔 누르는 것
auto-day.cmd          오늘 글 예약발행 (네이버 → 티스토리)
                      아침 자동 실행이 안 됐을 때 더블클릭. 이미 된 글은 건너뛰어요.

reserve-tomorrow.cmd  내일 글(네이버·티스토리)을 오늘 밤 미리 예약
reserve-week.cmd      앞으로 7일치 글(네이버·티스토리·철거)을 한꺼번에 예약

reserved-redo.cmd     이미 예약한 글을 새 그림으로 다시 예약 (Claude 가 말할 때만)

matjip.cmd            맛집 글 네이버 임시저장 (Claude 가 말할 때만)

sync.cmd              최신 내용 받기 (Claude 가 "받아 주세요"라고 할 때)


■ 로그인이 풀렸다는 알림을 받았을 때
chrome-login.cmd      네이버·티스토리 로그인 확인
two-blog-test.cmd     다와이철거 블로그(breakandbuild) 로그인
threads-key.cmd       스레드 키 다시 넣기 (스레드 글이 안 올라간다는 알림 때)


■ 처음 한 번만
auto-setup.cmd        작업 스케줄러 등록 (새 PC 를 쓸 때)


■ 건드리지 않는 것
PAUSE-ON-WAKE         PC 를 켰을 때 자동 작업을 멈추는 표시 (2026-11-12 사용자)
tools 폴더            위 실행기와 작업 스케줄러가 쓰는 부품
