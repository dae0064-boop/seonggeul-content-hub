===================================================================
  ClaudeWorkspace - 새 컴퓨터 연결하기
===================================================================

이 파일은 2호기 / 3호기에서 읽으라고 남겨 둔 것입니다.
순서대로 따라 하시면 됩니다. 5분이면 끝납니다.


현재 진행 상황
-------------------------------------------------------------------
  [완료]  1호기 - 집 PC (Windows)  2026-09-11 연결됨
  [   ]  2호기
  [   ]  3호기

지금 몇 대가 연결됐는지 궁금하면 status.cmd 를 더블클릭하세요.


===================================================================
0단계. 준비물 확인  (이 컴퓨터에서 처음이라면)
===================================================================

(1) Google Drive for Desktop

    탐색기(내 PC)를 열었을 때 "내 드라이브" 가 보이나요?

      보인다    -> 1단계로 넘어가세요.

      안 보인다 -> 아직 이 컴퓨터에 Drive 가 설치되지 않았습니다.
                  https://www.google.com/drive/download/
                  설치한 뒤 dae0064@gmail.com 으로 로그인하세요.
                  로그인 후 파일이 다 내려올 때까지 기다립니다.
                  (트레이 아이콘이 "최신 상태" 가 될 때까지)

(2) Python

    connect.cmd 가 알아서 확인합니다. 없으면 설치 방법을 알려주고
    멈추니, 미리 신경 쓰지 않아도 됩니다.

    미리 깔아두고 싶으면 PowerShell 에서:
        winget install Python.Python.3.12
    설치 후에는 창을 닫았다가 새로 여세요. (그래야 인식됩니다)


===================================================================
1단계. 연결하기
===================================================================

탐색기에서 이 폴더를 엽니다:

    내 드라이브 > ClaudeWorkspace

그 안의  connect.cmd  를 더블클릭하세요.

끝입니다. 검은 창이 뜨고 진행 상황이 보입니다.


===================================================================
2단계. 이렇게 나오면 성공
===================================================================

  ================================================
    ClaudeWorkspace - 이 컴퓨터를 연결합니다
  ================================================

  워크스페이스: G:\내 드라이브\ClaudeWorkspace

  Drive 에 있는 도구를 사용합니다.

    도구 복사됨: ...
    포인터 기록됨: ...
    훅 설치됨: SessionStart=pull, Stop=push ...

  첫 동기화를 시작합니다.
  Drive -> 공유 메모리
    <- CLAUDE.md
  ...
  완료. 이제 작업은 ...\ClaudeWorkspace\projects 아래에서 하세요.

핵심은 마지막 "완료" 줄입니다. 이게 나오면 된 겁니다.
드라이브 문자가 G: 가 아니어도 (D:, H: 등) 괜찮습니다.


===================================================================
3단계. 확인
===================================================================

같은 폴더의  status.cmd  를 더블클릭하세요.

  - 등록된 컴퓨터 수가 늘어났는지
  - 마지막에 "이상 없습니다" 가 나오는지

두 가지가 맞으면 완료입니다.


===================================================================
이후 지켜야 할 것 - 이것 하나뿐입니다
===================================================================

한 번에 한 컴퓨터에서만 작업하세요.

  1. 작업을 마칩니다.
  2. Drive 트레이 아이콘이 "최신 상태" 가 될 때까지 기다립니다.
  3. 그다음에 다른 컴퓨터를 켭니다.

이 순서를 어기면 같은 파일이 양쪽에서 바뀌어 충돌이 납니다.
충돌이 나도 내용은 지워지지 않습니다. memory\.conflicts\ 에 사본이
남고, 어느 쪽을 남길지 나중에 고를 수 있습니다.

작업은 항상 여기서 하세요:  ClaudeWorkspace\projects\


===================================================================
안 될 때
===================================================================

* "Python is not installed"
  -> 화면에 나온 winget 명령으로 설치하고, 창을 닫았다 다시 연 뒤
     connect.cmd 를 다시 더블클릭하세요.

* "도구를 받아오지 못했습니다"
  -> 두 가지 중 하나입니다.
     (1) Drive 동기화가 아직 안 끝났다
         -> 트레이 아이콘이 "최신 상태" 가 될 때까지 기다린 뒤 재시도
     (2) 회사 네트워크가 github.com 을 막는다
         -> 1호기가 이미 연결돼 있으므로, Drive 동기화만 끝나면
            인터넷 없이도 연결됩니다. 동기화를 먼저 기다려 보세요.

* connect.cmd 가 안 보인다
  -> Drive 동기화가 아직 안 끝난 것입니다. 기다렸다가 새로고침(F5).

* 그 밖의 오류
  -> 검은 창의 내용을 통째로 복사해 두었다가 Claude 에게 보여주세요.
     창이 닫히기 전에 마우스로 드래그 + 마우스 오른쪽 버튼으로 복사됩니다.
