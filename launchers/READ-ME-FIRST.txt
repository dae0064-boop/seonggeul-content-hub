성글벙글 실행기 — 더블클릭하는 것은 이 다섯 개뿐이에요
=====================================================

평소에는 아무것도 누르지 않아도 돼요.
아침에 일어나 PC 를 켜거나 잠금을 풀면 그때 바로 오늘 글 예약발행이 시작돼요 (05~15시, 남은 글이 있을 때만).
작업이 다 끝나면 "10분 뒤 PC 를 끕니다" 창이 떠요. [끄지 않기] 를 누르지 않으면 PC 가 꺼져요 (2026-10-09~).
꺼진 다음 날은 아침에 전원을 켜고 로그인하면 바로 시작해요.


auto-day.cmd          오늘 글 예약발행 (네이버 → 티스토리)
                      아침 자동 실행이 안 됐을 때 더블클릭. 이미 된 글은 건너뛰어요.

reserve-tomorrow.cmd  내일 네이버 글을 오늘 밤 미리 예약
                      다음 날 아침 PC 를 못 켤 때.

shutdown-test.cmd     "PC 끄기" 창 시험 (정말 꺼져요 — 먼저 문서를 저장)
                      1분짜리 창이 떠요. [끄지 않기] 를 누르면 켜 둬요.

chrome-login.cmd      로그인 확인 (네이버·티스토리)
                      "로그인이 풀렸다"는 알림을 받았을 때. 풀린 곳만 로그인 탭이 열려요.

sync.cmd              최신 내용 받기 + 보험글 Word 저장
                      Claude 가 "받아 주세요"라고 할 때.

auto-setup.cmd        아침 자동 실행 등록 (PC 마다 처음 한 번만)
                      노트북은 auto-setup.cmd -At 09:15

goms-test.cmd         GOMS 광고심의 등록 시험 (시험 중에만 — 등록은 누르지 않아요)
                      칸을 채운 화면을 Drive 에 올려 Claude 가 확인해요.

goms-register.cmd     GOMS 광고심의 실제 등록 — 몇 편부터 몇 편까지 물어봐요 (이미 등록한 편은 건너뜀)


tools 폴더            위 실행기가 쓰는 부품이에요. 열거나 누를 필요 없어요.
                      (새 PC 를 연결할 때 쓰는 connect.cmd·openai-key.cmd 도 여기 있어요)
