# 네이버 클립 (2026-11-05 사용자 — "네이버 클립부터 진행해줘")

수익화 2단계 중 1번째. 매일 발행된 네이버 글(생활보장 먼저) 1편을 **세로 영상(1080×1920, 약 20초, 소리 없음, 그림 값 0원)** 으로 만들어 클립에 올린다.

- 영상: `scripts/clip/make-clip.mjs` — 원고의 제목 · '•' 한눈에 보기 · [노란배경] 한 문장 · Q1/A1 · "네이버에서 '<메인 키워드> 성글벙글' 검색". 원고에 없는 말은 넣지 않는다. PC 에 그 글 대표사진이 있으면 표지에 깐다.
- 올리기: `scripts/clip/upload-clip.mjs` (clipcreators.naver.com, 자동화용 크롬 9222). 설명 300자 안쪽, 링크 없음(클립 설명은 링크를 못 단다).
- PC: `launchers/tools/clip-day.ps1` — `catchup-reserve.ps1` 안에서 하루 한 번.
- **아직 실제 화면을 본 적이 없다** (클라우드는 naver.com 이 막혀 있다). 그래서 단계별로:
  1. 첫 실행: 화면 살펴보기(`--look`) — 단추·입력 칸·캡처를 Drive `run-logs/clip-<시각>-<PC>/` 로.
  2. 그다음: 영상·설명까지 넣고 **올리지 않고** 멈춤 — 기록을 보고 선택자를 맞춘다.
  3. 화면이 맞으면 Claude 가 `content/clip/POST-OK` 파일을 만들어 main 에 → 그때부터 실제로 올린다 (하루 1편).
- **시작일 2026-11-09(월)** (사용자 — "다음 주 월요일부터") — `content/clip/start.txt`.
- 멈춤: `content/clip/PAUSE`.
- 보험 상담을 권하는 말·보험사·상품 이름은 넣지 않는다 (블로그 생활보장 글과 같은 비상업 정보). 심의받은 인스타 카드뉴스는 다른 매체라 쓰지 않는다.
- 클립 크리에이터 수익 프로그램(미션: 한 정리 글 기준 매월 영상 10건 또는 게시물 15건)은 모집 때 사용자가 신청해야 할 수 있다 — 하루 1편이면 영상 미션 기준을 넘는다.
