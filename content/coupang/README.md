# 쿠팡 파트너스 원고 (손으로 올리는 글)

2026-10-17 사용자 결정 — 정보성 글 + 쿠팡 상품 링크 1개 + 공정위 문구, 가끔만.
**자동 발행 대상이 아니다.** 아침 자동 실행은 `content/posts/` 만 보므로 여기 둔 원고는 예약되지 않는다
(링크 없이 예약되는 것을 막기 위해 일부러 따로 둔다).

순서
1. 클라우드 대화에서 원고를 쓰고 `node scripts/lint-post.mjs content/coupang/<원고>.md` 통과.
2. 데스크톱 앱 대화(내장 브라우저)에서 사용자가 쿠팡 파트너스에 로그인 → Claude 가 인기 상품을 골라 링크 생성.
3. 원고의 `[쿠팡 링크 자리]` 줄을 상품 한 줄 소개 + 링크로 바꾼다. 링크는 한 글에 1개.
4. 네이버 글쓰기 화면에 넣고, 발행은 사용자 확인 뒤에 한다.

지킬 것
- 공정위 문구는 고정 인사말 바로 아래에 그대로 둔다:
  "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- 단축 주소·리디렉션으로 쿠팡 주소를 숨기지 않는다.
- 써 보지 않은 제품을 써 본 것처럼 쓰지 않는다. 상품 소개는 원고의 비교 기준(넓이·소리·관리)에 맞춰 사실만.
- 보험 글에는 넣지 않는다.
