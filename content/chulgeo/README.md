## 2. 지켜야 할 것 (광고 글이라 더 엄격하게)

- **받은 사실만 쓴다.** 경력 숫자는 "7년", "1,400건 이상" 그대로. 늘리거나 바꾸지 않는다.
- **과장·비교 금지**: 최저가, 업계 1위, 최고, 1등, 무조건, 100%, 완벽, 국내 유일, 타 업체 비방. (표시·광고의 공정화에 관한 법률 — 검사기가 막는다)
- **금액을 쓰지 않는다** (공개 가능한 금액을 아직 받지 못했다). 비용 글은 "무엇에 따라 달라지는지"만.
- **"무료", "추가금 없음"을 쓰지 않는다** (확인 안 됨).
- 관리사무소 신고·동의서는 "대행하지 않는다, 고객이 준비한다"로만 쓴다. 준비 방법 안내는 해도 된다.
- 방문 견적 지역은 서울·인천·시흥만. 수원·안산·안양 글은 "사진으로 먼저 상담 → 필요하면 일정 조율"로 쓴다.
- **후기·사례를 지어내지 않는다.** "지난주 ○○아파트 현장에서" 같은 실제 있었던 일처럼 쓰지 않는다.
  일반화한 설명("이런 경우가 많아요", "예를 들어 ~라면")으로 쓴다.
- **사진**: 실제 현장 사진이 없으므로 AI 실사 그림을 **예시 이미지**로 쓴다. 본문 첫 그림 바로 아래에
  `글 속 사진은 이해를 돕기 위한 예시 이미지예요.` 를 그대로 넣는다 (검사기). "저희가 작업한 현장" 처럼 보이게 쓰지 않는다.
  사용자가 실제 현장 사진을 주면 그 사진을 우선한다 (프런트매터 `real_photos: yes` — 그때 검사기를 고친다).
- 안전·법령 이야기(석면, 건설폐기물, 소음 시간 등)는 1차 원문(법령·환경부·고용노동부·지자체)으로 확인한 것만. 확인 못 하면 쓰지 않는다.
- 같은 문장을 글마다 복사하지 않는다 — 네이버가 같은 글로 묶으면 검색에서 빠진다(유사문서). 검사기가 다른 철거 글과 겹침을 본다.

### 분량·키워드·서식 (검사기 `node scripts/chulgeo/lint.mjs <원고>`)

- 본문 공백 제외 **1,600~2,300자**
- 프런트매터 `main_keyword` = **지역 + 철거 종류** (예: 인천 아파트 철거, 시흥 상가 철거, 안양 원상복구). 본문 6회 이상
- `sub_keywords` 2~3개, 각 3회 이상. 제목은 메인 키워드로 시작, 40자 안쪽
- 한 줄 30자 이하, 덩어리 4줄 이하, 소제목 바로 아래 덩어리 3줄 이하
- 강조: 빨강 1~4, 파랑 3~10, 노랑 1~4 (성글벙글과 같은 표기 `[빨간글씨]…[/빨간글씨]`)
- 그림 8자리 `[이미지 1]`~`[이미지 8]`, 계획서 `content/chulgeo/image-plans/<슬러그>.json` 8장 (실사풍, 정보 카드 0~3장)
- 태그 10~15개, `다와이철거` 포함
- `topic: 인테리어·DIY` (네이버 주제). `category` 는 비워 둔다 (블로그에 카테고리를 만들면 그 이름을 넣는다)
- `publish_at` 은 11:00 · 13:00 · 16:00 · 18:00 · 20:00 (성글벙글 10·12·15·17·21시와 겹치지 않게)
