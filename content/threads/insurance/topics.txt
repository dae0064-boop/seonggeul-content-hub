# 스레드 보험 심의글 글감

# 형식:  역할 | 보험 종류 | 글감
# 역할은 rules.md 의 다섯 칸(오해풀기 / 숨은권리 / 증권한줄 / 생활장면 / 마음이야기) 중 하나.
# 한 묶음은 역할마다 하나씩, 보험 종류가 겹치지 않게 5개를 고른다.
# 쓴 것은 지우지 말고 앞에 "# 사용 <날짜> " 를 붙인다. 같은 글감을 또 쓰지 않기 위해서다.
# 숫자·기간이 들어가는 글감은 쓰기 전에 1차 출처를 찾는다. 못 찾으면 숫자 없이 쓴다.
