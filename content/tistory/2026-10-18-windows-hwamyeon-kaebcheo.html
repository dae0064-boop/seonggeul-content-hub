“윈도우 화면 캡처 단축키 4가지

[이미지 2] 윈도우 화면 캡처 단축키 4가지를 정리한 카드

마이크로소프트 도움말 기준으로 정리하면
윈도우 화면 캡처 단축키는 이 4가지예요.

 

✔ 윈도우 키 + Shift + S는 부분 캡처
✔ 윈도우 키 + PrtScn은 파일 저장
✔ Alt + PrtScn은 지금 창만 복사
✔ PrtScn은 전체 화면 복사

 

복사만 되는 단축키는 붙여넣기를 해야 보여요.
메신저나 문서에서 Ctrl + V를 누르면 나타나요.

“부분 캡처는 윈도우 키 + Shift + S

[이미지 3] 부분 캡처하는 순서를 정리한 카드

이 단축키를 누르면 캡처 도구가 열리고
화면 위쪽에 캡처 모양을 고르는 막대가 떠요.

 

① 단축키로 캡처 도구 열기
② 사각형, 자유형, 창, 전체 화면 중 고르기
③ 드래그로 범위 정하기
④ Ctrl + V로 붙여넣기

 

사각형과 자유형은 마우스로 끌어 범위를 정하고,
창과 전체 화면은 고르는 순간 바로 찍혀요.
자유형은 손으로 그리듯 모양을 따라 잘라요.
부분 캡처한 그림은 클립보드에 자동으로 복사돼요.

 

찍은 뒤 화면 구석에 뜨는 알림을 누르면
캡처 도구 창이 열려요.
펜으로 표시를 하거나
Ctrl + S로 파일 저장도 할 수 있어요.

“전체 화면을 파일로, 윈도우 키 + PrtScn

[이미지 4] 거실 테이블 위 모니터 앞에서 사진 앨범을 정리하는 중년 남성

윈도우 키와 PrtScn 키를 함께 누르면
화면이 잠깐 어두워졌다 돌아와요.
그게 저장됐다는 신호예요.

 

파일은 사진 폴더 안의
스크린샷 폴더에 쌓여요.
파일 탐색기에서 사진을 열면 스크린샷 폴더가 보여요.

 

여러 장을 연달아 남겨야 할 때 편해요.
설명서처럼 화면을 순서대로 모아 둘 때도 좋아요.

 

붙여넣기를 할 필요 없이
스크린샷 폴더에 차례로 쌓이니
나중에 한꺼번에 골라 쓰면 돼요.

 

OneDrive 설정에 따라 캡처가
OneDrive 쪽에 저장되기도 해요.
스크린샷 폴더에 없다면
OneDrive 폴더 안도 열어 봐요.

“지금 보는 창만, Alt + PrtScn

[이미지 5] 카페 테이블에서 노트북 화면 하나를 가리키며 설명하는 청년

모니터에 창이 여러 개 떠 있을 때
지금 쓰고 있는 창 하나만 찍고 싶다면
Alt + PrtScn이에요.

 

작업 표시줄이나 바탕화면은 빠지고
그 창 테두리 안만 클립보드에 복사돼요.
파일로 남지 않으니 바로 붙여넣기를 해요.

 

찍기 전에 원하는 창을 한 번 클릭해
앞으로 올려 두는 게 요령이에요.
다른 창이 선택돼 있으면 그 창이 찍혀요.

 

오류 창을 회사 담당자에게 보낼 때처럼
필요한 부분만 깔끔하게 전할 때 좋아요.
화면 전체가 찍혀 개인 창이 함께 보일 걱정도 덜어요.

“PrtScn 키만 눌렀을 때

[이미지 6] 사무실 책상에서 키보드 오른쪽 위 키를 손가락으로 누르는 여성

PrtScn 키만 누르면 전체 화면이

그런데 윈도우 11에서는 설정에 따라
캡처 도구가 대신 열리기도 해요.

 

설정, 접근성, 키보드로 들어가면
Print Screen 키로 화면 캡처를 여는
항목이 있어요.

 

켜면 캡처 도구, 끄면 예전처럼 전체 복사예요.
내가 원하는 쪽으로 한 번 맞춰 두면
누를 때마다 헷갈리지 않아요.

“노트북에서 캡처가 안 될 때

[이미지 7] 기차 좌석 테이블 위 노트북 키보드를 내려다보는 대학생

✔ PrtScn이 Fn 키와 같이 쓰는 키인지
✔ 키보드에 PrtScn 키가 아예 없는지
✔ 윈도우 업데이트가 밀려 있지 않은지

 

노트북은 Fn 키를 누른 채 PrtScn을 눌러야

PrtScn 키가 없는 기기는
Fn + 윈도우 키 + 스페이스바가 안내돼 있어요.

 

윈도우 화면 캡처 단축키가 갑자기 안 먹힌다면

복사는 다음 캡처를 하면 앞의 것이 덮어써져요.
두 장 이상 필요하면 한 장씩 붙여넣거나
처음부터 파일로 남기는 쪽을 골라요.

“윈도우 화면 캡처 단축키 Q&A

윈도우 화면 캡처 단축키에 많이 묻는 세 가지예요.

 

Q1: 캡처한 그림이 어디에도 없어요.
A1: 부분 캡처나 Alt + PrtScn은
복사만 되고 파일로 남지 않아요.
그림판이나 메신저에 Ctrl + V를 눌러 보세요.

 

Q2: 화면을 동영상으로도 찍을 수 있나요?
A2: 캡처 도구에서
윈도우 키 + Shift + R을 누르면
화면 녹화를 시작할 수 있어요.

 

움직이는 순서를 보여 줘야 할 때 쓰면 좋아요.
한 장짜리 캡처로는 설명이 어려운 경우예요.

 

Q3: 윈도우 10에서도 똑같나요?
A3: 윈도우 화면 캡처 단축키는 대부분 같지만
메뉴 이름과 위치는 버전마다 조금 달라요.
설정 검색창에 캡처라고 쳐 보면 빨라요.
