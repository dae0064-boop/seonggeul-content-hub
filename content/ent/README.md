## 1. 목표

- 1순위 **홈판(네이버 메인 추천) 노출**, 2순위 검색 유입. 수익은 애드포스트(+ 나중에 쇼핑커넥트).

## 2. 글감 고르기 (매번)

1. 크리에이터 어드바이저 → 데이터랩 → **메인 유입 트렌드** 1~20위: 지금 네이버 메인이 미는 주제·인물·방송을 본다.
2. 크리에이터 어드바이저 → 트렌드 → **주제별 인기유입검색어**(방송·연예): NEW·급상승인 말을 고른다. 이미 다 쓴 이슈보다 막 뜬 이슈.
3. 그 말을 네이버 검색창에 넣어 **자동완성·연관 검색어**를 2~4개 모은다.
4. **A 말고 B**: 모두가 쓰는 관점(A, 예: 수상)이 아니라 옆 질문(B, 예: 수상 소감 속 가족 이야기)을 잡는다.
5. 사실 확인 — 아래 3 ① 을 통과한 것만 쓴다.

## 3. 반드시 지킬 것

① **사실만.** 방송 본편·공식 발표(방송사·소속사)·언론사 2곳 이상이 같이 전한 것만. 소문·추측·커뮤니티 글은 쓰지 않는다.
   방송 이야기는 방송명·회차·방송일을 본문에 적는다.
② **없는 사실로 제목을 낚지 않는다.** 이름 숨김·반전은 되지만 일어나지 않은 일을 제목에 쓰지 않는다 (강의도 저품질 원인으로 꼽음).
③ **비방·악플성 글 금지** — 외모 비하, 사생활(연애·가족) 추측, 단정적 비난, 범죄 혐의 단정. 확인된 사건도 "~로 알려졌다 / ~라고 밝혔다"로.
④ **기사 문장을 옮기지 않는다.** 사실만 가져와 우리 말로 다시 쓴다. 인용은 한 문장 안쪽 + 출처.
⑤ 미성년 출연자·일반인 출연자의 사생활은 다루지 않는다.

## 5. 이미지 — 저작권 걱정 없는 것만

강의는 "언론사 사진만 조심하면 된다, GPT가 준 사진·방송 캡처도 괜찮다, 출처 안 밝혀도 된다"고 했지만 **따르지 않는다**
(근거: 강의 정리 6절. 네이버 가이드도 "출처 표기는 면책 사유가 아니다").

| 쓴다 | 쓰지 않는다 |
|---|---|
| 글자 카드형 대표사진 (단색·그라데이션 + 큰 글씨 두 줄) | 뉴스·기사 사진 |
| 인물 없는 AI 장면 (무대 조명, 빈 촬영장, 옷걸이의 코트, 꽃다발, 트로피) | 방송 화면 캡처, 드라마·예능 장면 |
| 정보 카드 (방송일·회차·한 줄 요약, 출연작 연표) | 연예인 SNS 사진 |
| 사용자가 직접 찍은 사진 | **실존 인물 얼굴 AI 그림** |
| **공식 유튜브 영상 삽입** (방송사·소속사 채널 — 링크로 넣기, 캡처 금지) | GPT·구글 이미지 검색으로 찾은 사진 |

- 대표사진은 글자 카드형이 기본. 강의도 "비슷한 글자 썸네일은 역효과"라고 했으니 **색·글씨체·배치를 글마다 바꾼다**.
- 본문 사진 4장 이상 = AI 장면 2~3 + 정보 카드 1~2 (+ 공식 영상 1, 장수에 안 셈).
- AI 장면은 "티 나는 AI"가 아니게 — 사진처럼 자연스러운 조명·구도 (강의 4:19).
