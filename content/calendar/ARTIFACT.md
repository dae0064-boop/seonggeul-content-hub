# 발행 캘린더 아티팩트 — 고정 주소

```
https://claude.ai/code/artifact/87062107-9b09-4a3e-a6ce-02fc0dbb924e
```

**이 주소는 바뀌면 안 된다.** 매달 월말 내용만 갈아끼운다.

소스: `content/calendar/publish-calendar.html`

## 갱신 방법

같은 대화에서라면 같은 파일 경로로 다시 발행하면 주소가 유지된다.

**다른 세션에서 갱신할 때는 반드시 `url` 파라미터에 위 주소를 넘긴다.**
넘기지 않으면 별개의 새 아티팩트가 생기고 주소가 갈린다.

```
Artifact(
  file_path: "content/calendar/publish-calendar.html",
  url: "https://claude.ai/code/artifact/87062107-9b09-4a3e-a6ce-02fc0dbb924e"
)
```

발행 전에 `action: "read"` 로 현재 버전을 먼저 읽는다. 이 대화에서 읽거나
발행한 적 없는 아티팩트에 바로 쓰면 거부된다.

`favicon` 과 `icon` 은 재발행 시 넘기지 않는다. 넘기면 아이콘이 바뀐다.

## 월말 갱신 절차

1. 각 채널 성과 분석 (조회수·유입 키워드·홈판 노출 여부)
2. 성과가 나온 글감 유형을 익월 배분에 반영
3. 익월 날짜 앵커를 **검색으로 재확인** (명절·제도 시행일·접종 일정 등)
4. `publish-calendar.html` 의 `W` 배열과 `ANCHORS` 배열을 교체
5. 헤더의 계획 기간 / 작성 기준일 / 다음 개정일 갱신
6. 위 `url` 로 재발행

## 표기 규칙

- 날짜 근거를 검색으로 확인한 항목에만 배열 4번째 값에 `1` 을 넣어 `검증` 배지를 띄운다.
- 확인하지 못한 글감에는 절대 `검증` 을 붙이지 않는다. 추측을 근거처럼 보이게 하면 안 된다.
