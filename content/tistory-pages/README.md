# 티스토리 고정 페이지 (애드센스 심사용, 2026-11-03)

애드센스 심사는 "누가 운영하는 사이트인지, 방문자 정보를 어떻게 다루는지, 연락할 길이 있는지"를 본다.
그래서 세 페이지를 블로그에 **공지**로 한 번 올려 둔다. 원고는 이 폴더에 있고, 올리는 것은 사용자가 한 번만 한다 (`docs/TISTORY-SEARCH.md` 4).

| 파일 | 공지 제목 |
|---|---|
| `about.txt` | 성글벙글 블로그 소개 |
| `privacy.txt` | 개인정보처리방침 |
| `contact.txt` | 문의하기 |

- 날마다 나가는 원고가 아니므로 `content/tistory/` 에 두지 않는다 (검사기·발행 스크립트가 건드리지 않게).
- 내용을 바꾸면 이 파일을 고치고, 사용자에게 공지 글을 고쳐 달라고 한다.
- 개인정보처리방침의 광고·제휴 문단은 실제로 쓰는 것(구글 애드센스·쿠팡 파트너스·티스토리 방문 통계)만 적었다. 새 광고·분석 도구를 붙이면 여기에도 더한다.
