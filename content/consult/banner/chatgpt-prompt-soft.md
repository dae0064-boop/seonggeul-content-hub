1. ChatGPT 에 **본인 사진 파일을 먼저 첨부**한다 (+ 버튼 → 사진 올리기).
2. 아래 상자 안 글을 통째로 붙여 넣고 보낸다.
3. 받은 그림을 Claude 대화에 올리면 1920×600 으로 맞추고 깨진 한글을 고친다.

```
첨부한 사진 속 남성을 그대로 넣어서, 네이버 블로그 맨 위에 들어갈 가로로 아주 긴 배너를 만들어 줘. 비율은 가로:세로 = 3.2:1 (최종 1920×600px).

[사진]
- 첨부한 사람의 얼굴·머리·옷을 바꾸지 말고 그대로 써 줘. 다른 사람처럼 보이면 안 돼.
- 가로 60~75% 자리에, 동그란 액자(흰 테두리, 뒤에 연한 살구색 동그라미) 안에 가슴 위까지 넣어 줘.
- 액자 아래에 흰색 둥근 이름표 "강성대".

[분위기]
- 부드럽고 편안한 느낌. 아이보리·웜베이지 바탕, 세이지 그린(#6E8B6B)과 연한 살구색(#E2A07A)을 포인트로.
- 양옆 끝에 연한 풀잎 줄기, 아주 옅은 동그라미 몇 개, 작은 하트 두어 개. 아래쪽에 낮은 베이지 언덕.
- 반짝이·금색·어두운 색은 쓰지 마.

[배치]

   - 중간 굵기 글씨 "병원비·보험금, 편하게 물어보세요" (아래에 연한 살구색 형광펜)

   - 흰색 둥근 칩 5개 한 줄: 실비·보험금 / 검진·질병 / 의료비·건강보험 / 돌봄·요양 / 지원 제도
```
