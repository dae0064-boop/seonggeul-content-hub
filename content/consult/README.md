# 상담 블로그 꾸미기 — 메인·소개글·카카오톡 채널·인스타 (2026-11-09 사용자)

사용자 결정: 생활보장 밖 카테고리(생활·정보·이슈·뉴스·연예·방송·맛집·나들이)를 모두 비공개로, 상담은 **카카오톡 채널**, **인스타**도 연결.
정본 계획 `standards/상담-유입-계획.md`.

## ⚠ 심의 경계 (memory/CLAUDE.md 광고심의)
- **심의 없이 바로 쓸 수 있는 것**: 블로그 이름·배너·카테고리·정보 소개글 — 상담·연락 권유, 설계사 신분·소속·연락처, 보험사·상품 이름이 **없을 때**.
- **GOMS 심의(적격 + 심의필번호)를 받은 뒤에만 쓰는 것**: 카카오톡 채널 링크·"상담" 단추, 설계사 소개, 인스타 프로필의 상담 안내, 상담형 글. 심의에서 알려 주는 필수 표시(소속·심의필번호 등)를 그대로 넣는다.
- 그래서 **1단계(지금)** 는 정보 블로그 모양으로 바꾸고, **2단계(심의 뒤)** 에 상담 단추를 붙인다.

## 1. 메인 배너 (PC 화면 맨 위, 1920×600)
지금 배너의 틀(가운데 제목 + 아래 카드 5개, 위젯 칸 위치)은 그대로 두고 **카드 5개를 생활보장 하위 카테고리**로 바꾼다 — 카드마다 링크 위젯이 이미 그 자리에 걸려 있어 주소만 바꾸면 된다.

| 칸 | 카드 글씨 | 연결할 하위 카테고리 | 사진 (사람 얼굴 없이) |
|---|---|---|---|
| ① | 실비·보험금 | 실비·보험금청구 | 병원 영수증과 진료비 세부내역서, 볼펜 |
| ② | 검진·질병 | 건강검진·질병정보 | 건강검진 결과지 봉투와 안경 |
| ③ | 의료비·건강보험 | 의료비·건강보험 | 계산기와 병원비 고지서 |
| ④ | 돌봄·요양 | 돌봄·요양 | 창가 의자 위 무릎담요와 찻잔 |
| ⑤ | 지원 제도 | 생활 지원 제도 | 정돈된 서류철과 도장 |

- 제목 "성글벙글" 은 그대로 (지금까지 쌓인 이웃·검색이 이 이름으로 기억한다).
- 부제: **"병원비·보험금, 혼자 헤매지 않게"** (정보 안내 — 상담 권유가 아니라 심의 전에도 쓸 수 있다).
- ChatGPT 에 넣을 문장: `content/blog-banner/chatgpt-prompt-care.md`. 받은 그림은 클라우드 대화가 1920×600 으로 맞추고 깨진 한글을 고친다.
- **2단계(카카오톡 채널 심의 뒤)**: 오른쪽 끝(가로 80~95%)에 "카카오톡 상담" 단추 칸을 하나 더한 판을 다시 만든다.

## 2. 블로그 소개글 (모바일에서 가장 먼저 보이는 글 — 배너는 모바일 앱에 안 나온다)
**1단계 (지금 바로)**
> 병원비·실비 청구·돌봄 제도를
> 공식 자료로 확인해 쉽게 정리합니다.
> 매일 아침 10시부터 새 글이 올라와요.

**2단계 (심의 뒤 — 심의필번호·필수 표시를 그대로 넣는다)**
> 병원비·보험금 청구, 혼자 헤매지 않게.
> [이름] [직함] · [소속]
> 궁금한 점은 카카오톡 채널 [채널 이름]
> [심의필번호]

- 블로그 별명: 1단계 "성글벙글", 2단계 "성글벙글 [이름]" 처럼 사람이 보이게 (한다팀장 블로그의 공감 4배 차이 — 사람이 보인다).
- 대표 카테고리(블로그 들어오면 처음 보이는 칸): **생활·보장** 전체.

## 3. 카카오톡 채널 (상담 창구)
1. 카카오톡 채널 관리자센터에서 채널을 만든다 (채널 이름·프로필 사진·소개).
2. 채널 이름·소개·자동 인사말도 보험 상담 광고라 **심의를 받는다** — 문구 초안은 Claude 가 `content/consult/` 에 만든다(11/11).
3. 심의 뒤: 블로그 소개글(2단계)·배너 단추·상담형 글 끝에 채널 링크. 정보글(매일 10편)에는 넣지 않는다 — 정보글은 지금처럼 "내 증권·약관에서 확인해 보세요"로 닫는다.

## 4. 인스타
- 인스타는 지금 **심의받은 카드뉴스**만 올리는 흐름(`content/instagram/README.md`, 게시는 멈춤·심의만 하루 3편).
- 연결: 인스타 프로필 링크 = 네이버 블로그 주소, 블로그 소개(2단계)·프로필의 SNS 칸 = 인스타 주소.
- 같은 글감으로 이어지게: 블로그 청구 글 → 같은 주제 카드뉴스(심의) → 카드뉴스 마지막 장·캡션에 카카오톡 채널(심의받은 문구).
- 인스타 게시를 다시 켤 때 사용자가 알려 주면 `content/instagram/PAUSE` 를 지운다.
