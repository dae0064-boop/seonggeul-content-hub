# 상담 준비 도우미 (2026-11-13 사용자 "다 진행해줘")

블로그 글과 별개로, **사용자(강팀장)가 실제 상담을 준비할 때** Claude 를 쓰는 방법이다.
보험설계사들이 AI 를 가장 많이 쓰는 곳 — ① 증권·약관 요약과 빠진 보장 확인 ② 상담 화법 연습 ③ 상담 뒤 정리 문자 — 을 이 저장소 방식으로 옮겼다.

## 🔒 손님 정보 규칙 (꼭 지킨다)
- **이 저장소는 공개다.** 손님 증권·이름·병명·연락처가 들어간 것은 **저장소·STATUS·커밋에 절대 넣지 않는다.** 결과는 대화 안에서만 주거나, 사용자가 원하면 비공개 아티팩트·Drive 로.
- 사용자에게 사진을 받을 때 **주민등록번호 뒷자리·계좌번호·전화번호는 가리고** 보내 달라고 한 번 말한다(이미 보냈으면 결과에 옮겨 적지 않는다).
- 결과물은 **설계사가 보는 자료**다. 손님에게 그대로 보내는 문서가 아니다 — 최종 판단·설명 의무는 설계사에게 있다.
- 보험사·상품을 고르거나 "이걸로 갈아타라"는 결론을 Claude 가 내지 않는다. 빠진 곳은 "확인할 것"으로만 적는다.

## 1. "증권 정리해줘" — 증권 요약표
사용자가 증권 사진·PDF 를 주고 "증권 정리해줘"라고 하면 묻지 말고 아래 모양으로 답한다.

```
■ 계약 한눈에
계약일 · 만기 · 납입 기간 · 피보험자 나이대(이름 X)

■ 금액이 정해진 보장 (정액)
| 보장 이름 | 금액 | 갱신/비갱신 | 메모(면책·감액 기간 등 증권에 적힌 것) |

■ 쓴 만큼 돌려받는 보장 (실손)
| 보장 이름 | 세대(가입 시기로 추정 — 추정이라고 적음) | 자기부담 | 메모 |

■ 증권만으로는 모르는 것 (약관·보험사에 확인할 것)
- 예: 수술비 특약의 '수술' 정의, 진단비의 진단 확정 기준

■ 상담 때 물어볼 질문 3~5개
- 예: 최근 5년 안 입원·수술, 지금 다니는 병원, 회사 단체보험 유무
```
- 증권에 없는 숫자를 지어내지 않는다. 흐리게 찍혀 못 읽은 칸은 "읽지 못함"으로.
- 여러 증권이면 마지막에 "겹치는 보장(예: 실손 2개 → 비례보상)" 한 칸을 더한다.

## 2. "청구 서류 알려줘" — 상황별 확인표
병명·상황을 말하면 아래처럼 **보통 필요한 것 + 보험사마다 다른 것**을 나눠 준다. 병원별·보험사별 정확한 목록은 보험사 확인으로 닫는다.

| 상황 | 보통 필요 | 경우에 따라 |
|---|---|---|
| 통원 실비 | 진료비 영수증, 진료비 세부내역서 | 처방전(약제비), 금액이 크면 진단서·소견서 |
| 입원 실비 | 입·퇴원확인서, 진료비 영수증·세부내역서 | 진단서 |
| 수술비 특약 | 수술확인서(수술명·날짜·수술코드) | 진단서, 수술기록지 |
| 진단비 | 진단서(진단명·질병코드) | 검사 결과지(조직검사 등) |
| 가족이 대신 청구 | 실손24 제3자 청구, 또는 위임장·신분증 사본·가족관계 서류 | 보험사 대리청구 양식 |

## 3. "상담 연습하자" — 롤플레잉
사용자가 상황을 말하면(예: "실비 청구 거절당해서 화난 손님") Claude 가 **손님 역할**을 한다.
- 손님은 현실처럼 말한다: 짜증·의심·"설계사들은 다 팔려고만 하잖아요" 같은 말 포함.
- 사용자가 "끝"이라고 하면 Claude 가 코치로 바뀌어 ① 잘한 말 2개 ② 바꾸면 좋을 말 2개(바꿔 말하기 예시) ③ 광고·판매 규칙에 걸릴 말(단정·과장·해지 권유)을 짚는다.
- 자주 쓰는 상황: 처음 만난 손님, 보험금 거절, "보험 너무 많은 것 같아요", 부모님 보험 정리, 가족이 대신 묻는 경우.

## 4. "정리 문자 써줘" — 상담 뒤 문자
상담에서 나눈 내용을 짧게 말해 주면 손님에게 보낼 정리 문자를 쓴다.

```
○○님, 오늘 시간 내주셔서 고맙습니다😊
오늘 함께 본 내용 정리해 드려요.

1. (확인한 것)
2. (손님이 준비할 서류·할 일)
3. (제가 확인해서 다시 알려 드릴 것 + 언제까지)

궁금한 점은 편하게 말씀 주세요.
```
- 손님이 할 일과 설계사가 할 일을 나눈다. 약속한 날짜를 적는다.
- 확정되지 않은 보험금 금액·지급 여부는 쓰지 않는다("확인해서 알려 드릴게요").

## 5. 블로그로 이어지는 것
상담에서 자주 나온 질문은(손님 정보를 빼고) "자주 받는 질문: ○○" 한 줄로 `content/experience/notes.md` 에 남긴다 → 정보글·상담형 글감이 된다. 이게 다른 블로그가 따라 할 수 없는 글을 만든다.
