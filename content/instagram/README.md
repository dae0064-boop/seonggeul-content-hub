| 6 | 체크리스트 + 행동 | 3가지 확인 → "저장하기 · 가족에게 공유 · 궁금하면 댓글에 화재보험" |

- 디자인: 1:1 검은 바탕, 굵은 손글씨체 흰 글씨, 키워드만 노랑, 장마다 낙서 아이콘 하나, 아래에 계정 이름 줄, 배경 음악.
- 본문 글(캡션): 카드 내용을 블로그처럼 길게 다시 풀고 같은 댓글 키워드로 닫음. 해시태그 3개뿐.

### 가져올 것
1. 표지 = 키워드(노랑) + 독자가 손해 보는 상황 질문. 한 장에 한 가지 말만.
2. `Fact` 라벨처럼 **사실 칸을 눈에 띄게** — 우리 1차 원문 확인과 잘 맞는다.
3. 숫자 예시 한 장 (300만원 → 30만원 같은 계산).
4. 끝에서 두 번째 장에 **체크리스트 + 저장·공유 + 댓글 키워드**.
5. 마지막 장 = 심의 고지 (우리는 스레드 배너 `content/threads/insurance/banners/base.jpg` 내용과 같은 칸).

### 따라 하지 않을 것 (심의 반려·반박 위험)
- 보험료 표·특정 회사가 "압도적", "완벽하게", "유일한 담보" 같은 단정 — 과장·비교광고로 반려되기 쉽고, 10/27 「실손 두 개」처럼 반박 댓글이 붙는다.
- "하나라도 안 되면 갈아타세요" — 승환 권유는 고지 문구가 길어지고 심의가 까다롭다. "내 증권에서 확인해 보세요"로 닫는다.
- 캐릭터·디자인·문구를 그대로 베끼지 않는다. 흐름만 참고하고 우리 색·우리 글감으로 만든다.

## 최종 모양 (2026-11-02 사용자 확정 — "좋아 이대로 진행하자")

1. **약관이 법보다 유리한 규정** — 예: 알릴의무는 상법 "계약일부터 3년" 외에 표준약관 "보장개시일부터 2년(진단계약 1년)". 원문(약관·표준약관)으로 확인해 같이 쓴다.
2. **실무에서 안 나오는 비용** — 예: 누수 때 내 집 배관 수리비·누수 탐지비. 나오는 것처럼 읽히는 문장을 두지 않는다.
3. **조건·예외** — 증권 주소, 중복 가입 비례보상, 기산점처럼 "그건 경우마다 다르다"는 반박이 나올 곳은 한 줄로 짚는다.
4. **자주 나오는 반대 질문** 하나를 카톡 장이나 본문에 미리 답한다.
- 11/2 세트(1~3편)에서 찾은 곳: STATUS 11/2 📸 항목 메모. 반려로 다시 쓰게 되면 같이 고친다.

## 설계안 넣기 (사용자가 설계안을 보내면)
- 편의 `cards` 에서 체크 장 앞에 `{"type":"plan","head":["…","[…]"],"cond":"20년납 90세만기 · 상해급수 1급 · 40세 남성","rows":[["담보명","가입금액"],…],"premium":"월 00,000원"}` 를 넣는다 → 장 수가 8장이 되고 쪽번호가 저절로 맞춰진다.
- 숫자·담보명은 **받은 설계안 그대로만** 옮긴다. 보험사·상품 이름은 넣지 않는다(심의). 장 아래에 약관 참조 문구와 "보험사 상품별, 성별, 연령, 직업 등에 따라 … 보험료는 달라질 수 있습니다" 가 저절로 붙는다.
- 게시물 본문에도 "📋 설계안 예시" 단락(조건 · 담보 · 월 보험료)을 같이 적는다.
