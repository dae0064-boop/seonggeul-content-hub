# 맛집 방문 메모 양식
#
# 이 파일을 복사해 content/matjip/notes/<슬러그>.txt 로 저장하고 채운다.
#   node scripts/matjip-draft.mjs content/matjip/notes/<슬러그>.txt
# → content/posts/<발행일>-<슬러그>.md 초안이 생긴다.
#
# 원칙: 직접 겪은 것만 적는다. 메모에 없는 맛·분위기·서비스는 원고에 지어 넣지 않는다.
#       모르면 비워 둔다. 비운 칸은 초안에 [채우기: …] 로 남고 검사기가 막는다.
# '#' 로 시작하는 줄은 무시한다. "키: 값" 한 줄씩. 목록은 [제목] 아래 "- " 로.

가게:
지역:                 # 예: 수원 인계동  (마지막 어절이 동네 이름으로 쓰인다)
대표메뉴:             # 예: 칼국수
방문일:               # 예: 2026-09-28
발행일:               # 예: 2026-10-05  (비우면 방문일 다음 날)
예약발행:             # 예: 13:00  (비우면 예약 안 함)
슬러그:               # 예: ingye-kalguksu  (영문 소문자·하이픈)
협찬:                 # 없음 / 있음: 식사 2인분 제공  ← 대가를 받았으면 반드시 "있음"

# 메인 키워드는 비우면 "<동네> <대표메뉴>", 서브 키워드는 "<동네>맛집, 메뉴, 주차"
메인키워드:
서브키워드:

주소:
영업시간:             # 예: 11:00~21:00 (브레이크 15:00~17:00)
휴무:
주차:                 # 예: 가게 앞 3대, 근처 공영주차장 1시간 1,000원
예약:                 # 예: 전화 예약 가능 / 안 받음
웨이팅:               # 예: 토요일 12시 도착, 20분 대기
가격대:               # 예: 1인 1만~1만5천원
방문계기:             # 왜 이 집에 갔는지 한두 줄 (예: 비 오는 날 따뜻한 국물이 당겨서)
함께간사람:           # 예: 가족 4명 / 혼밥  (원고에 그대로 쓰니 원하지 않으면 비운다)
