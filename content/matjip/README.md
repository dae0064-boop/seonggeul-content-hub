# 맛집 후기 양식 (성글벙글 · 맛집·카페 카테고리)

사용자가 **직접 가서 찍은 사진 5~8장**으로 손수 올리는 글의 틀이다 (2026-10-26 사용자 요청).
자동 원고 5편과 따로 간다. 자동 발행·검사기(`lint-post`)·AI 그림을 쓰지 않는다.
빈 원고 틀은 같은 폴더의 `template.md`.

## 왜 이 모양인가 — 근거

**① 우리 블로그 숫자** (Drive `blog-stats` 10/25 글별 조회수, `content/research/stats-log.md`)

- 「인천논현역 밥집 전주명가 순두부찌개 오징어볶음 점심 추천」(10/3) 이 하루 **13회로 블로그 전체 2위**였다.
  이 글보다 많이 읽힌 건 「되 돼 구분」 하나다. 3주가 지나도 꾸준히 읽혀 자동 원고 대부분보다 오래간다.
- 맛집 글로 들어온 검색어: `인천논현 밥집`, `인천 논현동 맛집 점심`, `논현동 순두부`, `논현동 짬뽕`, `시흥 카페고은`, `볼링장`.
  → **[지역·역] + [밥집/맛집/카페] + [상황(점심)]**, **[동네] + [메뉴 이름]**, **[지역] + [가게 이름]** 세 갈래로 들어온다.
- 유입 경로에 '플레이스'(1~11%)·'카카오맵'이 꾸준히 있다 → 글에 **네이버 지도(장소)를 꼭 붙인다.**

**② 다른 맛집 블로그·업계 글** (아래 출처)

- 검색하는 사람은 **매장 이름**으로 리뷰를 찾고, 예약 여부·주차·영업시간·대표 메뉴와 가격대를 본다.
- 점심 약속이면 빠른 식사·예약, 저녁 모임이면 단체석·주차가 더 중요하다 → **"누구와·언제 가면 좋은지"** 를 적는다.
- 모든 글을 똑같이 짜면 광고처럼 보인다 → 꼭 들어갈 칸만 정하고, 나머지는 그날 겪은 대로 쓴다.

**③ 우리 규칙** (`memory/CLAUDE.md`, `standards/이미지-기준.md`)

- 맛집 글은 **직접 찍은 사진만**. AI 그림을 실제 가게처럼 보이게 하지 않는다.
- 장점만 쓰지 않는다 → **아쉬운 점 한 가지**를 꼭 쓴다. 그게 후기를 믿게 만든다.
- 협찬·할인·무료 제공을 받았다면 **제목이나 글 맨 처음**에 눈에 띄게 밝힌다 (공정위 추천·보증 심사지침 — 2024-12 개정, 첫 부분 표시).
  내 돈으로 갔으면 "내돈내산"이라고 적는다.

## 글을 맡길 때 — 사용자가 보내 줄 것

사진 5~8장과 아래 메모만 보내면 Claude 가 `template.md` 틀로 원고를 쓴다.
**메모에 없는 것은 쓰지 않는다** (맛·가격·영업시간을 지어내지 않는다). 빈칸은 비워 두면 그 칸을 뺀다.

```
가게 이름:
지역·가까운 역 (예: 인천논현역 2번 출구 걸어서 5분):
간 날짜·시간대 (예: 10/24 금 점심 12시):
누구와 (예: 회사 동료 3명 / 아이 둘 데리고 가족):
내돈내산 / 협찬:
먹은 메뉴와 가격:
제일 맛있던 것과 그 이유 (한두 줄):
아쉬웠던 점 (한 가지):
웨이팅·예약:
주차:
영업시간·쉬는 날 (가게 앞·플레이스에서 본 대로):
아이·단체·혼밥 괜찮은지:
다시 갈지 (예 / 아니오 + 한 줄):
사진 순서 (예: 1 순두부 2 간판 3 안 4 메뉴판 ...):
```

영업시간·가격은 **간 날 본 것**을 적고, 글에 "(방문일 기준)"을 붙인다. 바뀌었을 수 있다.

## 제목

```
[지역·역] [밥집|맛집|카페] [가게 이름] [대표 메뉴 1~2개] [상황]
```

| 좋은 예 (우리 글) | 무엇이 들어갔나 |
|---|---|
| 인천논현역 밥집 전주명가 순두부찌개 오징어볶음 점심 추천 | 역 + 밥집 + 가게 + 메뉴 2 + 점심 |
| 시흥 카페 추천 카페고은, 두바이 쫀득쿠키와 소금빵 아메리카노 | 지역 + 카페 + 가게 + 메뉴 |
| 송도 미카도스시 가족 외식 후기, 아이와 먹기 좋은 회전초밥 | 지역 + 가게 + 상황 + 업종 |

- 맨 앞은 **지역·역 이름**. 사람들이 "○○역 맛집", "○○동 밥집"으로 친다.
- 가게 이름은 꼭 넣는다 — 가게 이름 검색이 맛집 글의 가장 큰 유입이다.
- 상황 말 하나: 점심 추천 · 가족 외식 · 아이와 · 혼밥 · 회식 · 데이트 · 주차 편한 · 24시간.
- 40자 안팎. "역대급", "인생 맛집", "무조건" 같은 과장은 쓰지 않는다.

## 사진 배치 (5~8장)

사진 1번이 대표사진(목록·홈판에 보이는 칸)이다. **가장 맛있어 보이는 음식 사진**을 1번에 둔다 — 간판이 아니다.

| 순서 | 8장일 때 | 5장일 때 |
|---|---|---|
| 1 | 대표 메뉴 (위에서 또는 45도, 가까이) | 대표 메뉴 |
| 2 | 간판·외관 (가게 이름 보이게) | 간판·외관 |
| 3 | 가게 안 (자리 배치·분위기) | 메뉴판 |
| 4 | 메뉴판 (가격 읽히게) | 함께 먹은 메뉴 / 반찬 |
| 5 | 상차림 전체 (반찬 포함) | 한입·단면 가까이 |
| 6 | 두 번째 메뉴 | |
| 7 | 한입·단면·끓는 모습 가까이 | |
| 8 | 주차장·입구·아이 의자 같은 쓸모 정보 | |

- 사진마다 **아래에 1~3줄**. 사진만 이어 붙이지 않는다.
- 사람 얼굴·다른 손님은 나오지 않게 (나오면 지우거나 다른 사진으로).
- 사진 파일 이름을 `가게이름-메뉴.jpg` 처럼 바꿔 올리면 이미지 검색에 조금 더 잡힌다.

## 본문 순서

```
고정 인사          안녕하세요 / 매일매일 좋은 날을 나누는 성글벙글입니다😊
내돈내산·협찬 한 줄  첫 덩어리 안에, 눈에 띄게
도입 2~3줄         어디·언제·누구와·왜 갔는지. 가게 이름 + 지역 한 번씩
[사진 1] 대표 메뉴
한 줄 결론         "순두부 하나만 보고 다시 갈 곳이에요" 같은 결론 먼저
기본 정보 상자      ✔ 줄 (주소·영업시간·쉬는 날·주차·예약·가격대) + 네이버 지도(장소)
[사진 2] 외관 → 찾아가는 길, 첫인상
[사진 3] 내부 → 자리·분위기, 누구와 오기 좋은지
[사진 4] 메뉴판 → 무엇을 왜 시켰는지, 가격
[사진 5~7] 음식 → 메뉴마다 맛·양·온도·간을 구체적으로
아쉬운 점          한 가지, 담백하게
방문 팁            ✔ 2~4줄 (웨이팅 피하는 시간, 주차, 아이 동반 등)
총평               이런 분께 추천 / 재방문 의사
댓글 질문          "여러분은 순두부 매운맛 몇 단계 드세요?" 처럼 한 단어로 답할 수 있게
닫는 인사          좋아요·공감과 이웃추가 부탁드려요💙 / 이상 성글벙글의 맛집 포스팅이었습니다😎
해시태그
```

소제목(인용구)은 3~5개면 충분하다 — 정보성 글처럼 7~9개를 채우지 않는다.

## 분량·키워드·강조

자동 원고 기준(2,100~2,300자, 키워드 10회, 소제목 7~9)을 **적용하지 않는다.** 맛집 글은 사진이 중심이다.

- 본문 **공백 제외 1,200~1,800자**. 사진 1장에 2~4줄.
- 메인 키워드(`[지역] [밥집|맛집|카페]`) **4~6회**, 가게 이름 **4~6회**, 대표 메뉴 이름 3회 안팎.
  억지로 넣지 않는다 — 맛집 글에 같은 말이 계속 나오면 바로 광고처럼 읽힌다.
- 줄 길이·덩어리는 평소와 같다 (한 줄 30자 안쪽, 2~4줄 덩어리).
- 색 강조는 줄인다: 빨간글씨 1~2 (한 줄 결론·아쉬운 점), 파란글씨 3~6 (가격·시간·거리), 노란배경 1~2 (방문 팁).
- 해시태그 10~15개 + 고정 3개(`서이추, 이웃추가, 서이추환영`).
  지역+맛집, 역+밥집, 가게 이름, 메뉴 이름, 지역+메뉴, 상황(점심·가족외식) 순서로.

## 하지 않는 것

- 먹지 않은 메뉴·가지 않은 날의 이야기를 쓰지 않는다.
- "인생 맛집", "역대급", "무조건 가세요" — 과장 금지.
- 다른 가게와 깎아내리며 비교하지 않는다.
- 협찬인데 내돈내산처럼 쓰지 않는다.
- 맛집 글에 보험 이야기를 넣지 않는다 (흐름이 끊기고 광고처럼 보인다).
- AI 그림을 넣지 않는다.
