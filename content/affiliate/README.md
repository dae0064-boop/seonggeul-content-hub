# 제휴 링크 원고 (손으로 올리는 글)

2026-10-17 사용자 결정 — **네이버 블로그는 네이버 브랜드커넥트(쇼핑 커넥트), 티스토리는 쿠팡 파트너스.**
같은 날 처음엔 네이버에 쿠팡을 넣으려다 바꿨다. 네이버 블로그에는 쿠팡 링크를 넣지 않는다.
정보성 글 + 상품 링크 1개 + 대가성 문구, 가끔만.

**자동 발행 대상이 아니다.** 아침 자동 실행은 `content/posts/`·`content/tistory/` 만 보므로 여기 둔 원고는 예약되지 않는다
(링크 없이 예약되는 것을 막기 위해 일부러 따로 둔다). 파일 이름: 네이버 `<날짜>-<슬러그>.md`, 티스토리 `tistory-<날짜>-<슬러그>.md`.

## 순서
1. 클라우드 대화에서 원고를 쓰고 검사기를 통과시킨다 — 네이버 `node scripts/lint-post.mjs content/affiliate/<원고>.md`.
2. 데스크톱 앱 대화(내장 브라우저)에서 사용자가 로그인 — 네이버 글은 브랜드커넥트, 티스토리 글은 쿠팡 파트너스.
   Claude 가 상품을 골라 링크를 만든다. 클라우드에서는 naver.com·coupang.com 이 막혀 있다.
3. 원고의 `[브랜드커넥트 링크 자리]`·`[쿠팡 링크 자리]` 줄을 상품 한 줄 소개 + 링크로 바꾼다. 링크는 한 글에 1개.
4. 글쓰기 화면에 넣고, 발행은 사용자 확인 뒤에 한다.

## 대가성 문구 (고정 인사말 바로 아래)
- 네이버(브랜드커넥트): 원고에는 "이 포스팅은 네이버 쇼핑 커넥트 활동으로 / 판매가 생기면 수수료를 받을 수 있어요." 를 넣어 두었다.
  **브랜드커넥트 화면이나 가이드에 정해진 문구가 있으면 그 문구로 바꾼다** (클라우드에서 공식 가이드를 열지 못해 확인 전).
- 티스토리(쿠팡): "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."

## 지킬 것
- 단축 주소·리디렉션으로 제휴 주소를 숨기지 않는다.
- 써 보지 않은 제품을 써 본 것처럼 쓰지 않는다. 상품 소개는 원고의 비교 기준에 맞춰 사실만.
- 보험(생활보장) 글에는 넣지 않는다.
- 티스토리 쿠팡 글도 티스토리 네 갈래(T1~T4, CLAUDE.md "티스토리 자동화") 주제 규칙을 따른다.
