# 제휴 링크 원고 (손으로 올리는 글)

2026-10-17 사용자 결정 — **네이버 블로그는 네이버 브랜드커넥트(쇼핑 커넥트), 티스토리는 쿠팡 파트너스.**
같은 날 처음엔 네이버에 쿠팡을 넣으려다 바꿨다. 네이버 블로그에는 쿠팡 링크를 넣지 않는다.
정보성 글 + 상품 링크 1개 + 대가성 문구, 가끔만.

- **네이버 브랜드커넥트 글은 손으로 올린다.** 원고는 이 폴더에 둔다 — 아침 자동 실행은 `content/posts/` 만 보므로 예약되지 않는다.
- **티스토리 쿠팡 글은 자동이다** (2026-10-17 사용자 — 티스토리 목표 ① 조회수 ② 수익). 밤 티스토리 Routine 이 하루 5편 중 T3 계산 글 1편까지
  `coupang:` 키워드를 달아 `content/tistory/` 에 쓰고, 아침 PC 의 build-tistory 가 `coupang-links.tsv` 의 링크를 `rel="sponsored"` 로 넣는다.
  사람 손은 링크 목록을 채울 때만 든다 (아래).

## 네이버 브랜드커넥트 글 순서
1. 클라우드 대화에서 원고를 쓰고 검사기를 통과시킨다 — 네이버 `node scripts/lint-post.mjs content/affiliate/<원고>.md`.
2. 데스크톱 앱 대화(내장 브라우저)에서 사용자가 로그인 — 네이버 글은 브랜드커넥트, 티스토리 글은 쿠팡 파트너스.
   Claude 가 상품을 골라 링크를 만든다. 클라우드에서는 naver.com·coupang.com 이 막혀 있다.
3. 원고의 `[브랜드커넥트 링크 자리]`·`[쿠팡 링크 자리]` 줄을 상품 한 줄 소개 + 링크로 바꾼다. 링크는 한 글에 1개.
4. 글쓰기 화면에 넣고, 발행은 사용자 확인 뒤에 한다.

## 티스토리 쿠팡 링크 목록 채우기 (가끔, 데스크톱 앱)
1. 아침 확인이 "쿠팡 링크 만들기" 를 안내하면(`coupang-wanted.txt` 5줄 이상) 데스크톱 앱 대화에서 "쿠팡 링크 만들어줘" 라고 한다.
2. 사용자가 partners.coupang.com 에 로그인 → Claude 가 키워드마다 인기·평점 높은 상품 또는 검색 결과로 파트너스 링크를 만든다.
3. `coupang-links.tsv` 에 `키워드<TAB>https://link.coupang.com/...<TAB>보여 줄 글자` 로 적고, `coupang-wanted.txt` 에서 지운 뒤 main 에 합친다.
   나중에 쿠팡 파트너스 Open API 키를 받을 수 있게 되면 이 단계를 PC 자동으로 바꾼다 (키는 PC `.env` 에만).

## 대가성 문구 (고정 인사말 바로 아래)
- 네이버(브랜드커넥트): 원고에는 "이 포스팅은 네이버 쇼핑 커넥트 활동으로 / 판매가 생기면 수수료를 받을 수 있어요." 를 넣어 두었다.
  **브랜드커넥트 화면이나 가이드에 정해진 문구가 있으면 그 문구로 바꾼다** (클라우드에서 공식 가이드를 열지 못해 확인 전).
- 티스토리(쿠팡): "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."

## 지킬 것
- 쿠팡이 만들어 준 `link.coupang.com` 주소 그대로 쓴다. 다른 단축 주소·리디렉션으로 제휴 주소를 숨기지 않는다.
- 써 보지 않은 제품을 써 본 것처럼 쓰지 않는다. 상품 소개는 원고의 비교 기준에 맞춰 사실만.
- 보험(생활보장) 글에는 넣지 않는다.
- 티스토리 쿠팡 글은 T3(생활 계산·비교)에서 하루 1편까지. 상품을 위해 주제를 고르지 않는다 — 조회수가 먼저다 (`routines/tistory-daily.md` 5-2).
