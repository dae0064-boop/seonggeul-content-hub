키워드 도구 설치

네이버 월간검색수를 받아오는 도구를 내 PC에 설치합니다.
아래 순서대로만 따라오시면 됩니다. 각 단계마다 성공 신호를 적어뒀으니, 그게 보이면 다음으로 넘어가세요.

1

검은 창 열기

앞으로 모든 명령은 이 창에 붙여넣습니다. 윈도우의 "명령 프롬프트"입니다.

키보드에서 Windows 키 + R 을 같이 누르고, 작은 창이 뜨면 cmd 라고 친 뒤 엔터.

검은 배경 창이 뜨면 성공입니다. 이 창을 끝까지 켜두세요.
2

준비물 확인

도구를 돌리려면 Node.js와 Git 두 가지가 필요합니다. 깔려 있는지 먼저 봅니다.

명령 프롬프트
node -v
v20.19.0 처럼 v로 시작하는 숫자가 나오면 OK
'node'은(는) 내부 또는 외부 명령... 이 아닙니다 가 나오면 → nodejs.org 에서 왼쪽 LTS 버튼으로 설치하세요. 설치 후 검은 창을 닫고 1단계부터 다시 해야 인식됩니다.
명령 프롬프트
git --version
git version 2.xx.x 가 나오면 OK
안 나오면 git-scm.com 에서 설치 후, 역시 창을 새로 여세요.
3

파일 내려받기

지금 코드는 GitHub에만 있습니다. 내 PC 문서 폴더로 복사해 옵니다.

아래 세 줄을 한 번에 복사해서 붙여넣고 엔터하세요.

명령 프롬프트
cd %USERPROFILE%\Documents
git clone -b claude/kind-dijkstra-qdzck2 https://github.com/dae0064-boop/seonggeul-content-hub
cd seonggeul-content-hub
-b claude/kind-dijkstra-qdzck2 부분이 꼭 있어야 합니다. 빼먹으면 빈 폴더만 받아집니다.

이어서 필요한 부품을 설치합니다. 1~2분 걸립니다.

명령 프롬프트
npm install

제대로 받아졌는지 봅니다.

명령 프롬프트
dir
아래 이름들이 목록에 보이면 성공입니다. package.json scripts content .env.example
.gitattributes 하나만 보이면 브랜치를 잘못 받은 겁니다. git checkout claude/kind-dijkstra-qdzck2 를 치세요.
4

열쇠 파일 만들기

발급받은 네이버 키 5개를 .env 라는 파일에 적어둡니다. 도구가 여기서 키를 읽습니다.

예시 파일을 복사한 뒤 메모장으로 엽니다.

명령 프롬프트
copy .env.example .env
notepad .env

메모장이 열리면 = 뒤에 값을 붙여넣으세요. 다섯 줄입니다.

NAVER_AD_API_KEY=검색광고 · 액세스 라이선스 (0100000... 로 시작하는 긴 값)
NAVER_AD_SECRET_KEY=검색광고 · 비밀키 (AQAAAAA... 로 시작, 끝의 == 까지 전부)
NAVER_AD_CUSTOMER_ID=검색광고 · 숫자만 6~8자리
NAVER_CLIENT_ID=개발자센터 · Client ID (짧은 영숫자)
NAVER_CLIENT_SECRET=개발자센터 · Client Secret
= 앞뒤에 띄어쓰기를 넣지 마세요. 따옴표도 붙이지 마세요.
올바른 예 → NAVER_AD_CUSTOMER_ID=1234567

다 채웠으면 Ctrl + S 로 저장하고 메모장을 닫습니다.

파일 위치는 package.json 이 있는 바로 그 폴더여야 합니다. 위 방법대로 하셨다면 자동으로 맞습니다.
5

열쇠가 맞는지 점검

키워드를 전부 돌리기 전에, 키가 제대로 들어갔는지만 확인합니다. 키워드 1개만 조회하니 부담 없습니다.

명령 프롬프트
node scripts/naver-keywords.mjs --check
이렇게 나오면 성공입니다.
✅ 인증 성공 — 연관키워드 12개 수신 예: 환절기 — PC 940 / 모바일 7300
화면에 키 값은 찍히지 않습니다. 글자 수만 나오니, 결과를 그대로 복사해서 보내주셔도 안전합니다.
6

전체 조회

5단계가 통과했을 때만 실행하세요. 키워드 70개를 조회합니다. 1~2분 걸립니다.

명령 프롬프트
node scripts/naver-keywords.mjs --keywords content/calendar/keywords.txt --with-competition
끝나면 이 두 파일이 생깁니다.
content\calendar\keyword-report.csv ← 엑셀로 열림 content\calendar\keyword-report.json

이 CSV 파일을 저에게 보내주시면 검색량 기준으로 발행 계획을 다시 짜겠습니다.

막혔을 때

검은 창이 어디 있는지 모르겠어요

Windows 키 + R → cmd → 엔터. 또는 시작 메뉴에서 "명령 프롬프트"를 검색하세요.

붙여넣기가 안 돼요

검은 창에서는 Ctrl+V 대신 마우스 오른쪽 클릭을 하면 붙여넣어집니다.

지정된 경로를 찾을 수 없습니다

폴더 위치가 어긋난 겁니다. cd %USERPROFILE%\Documents\seonggeul-content-hub 를 치고 다시 시도하세요.

.env 를 만들었는데 못 찾는대요

dir .env* 로 확인하세요. .env.txt 로 보이면 ren .env.txt .env 를 치세요.

그 밖의 오류

검은 창에 나온 글자를 그대로 복사해서 보내주세요. 키 값은 찍히지 않으니 안전합니다.
