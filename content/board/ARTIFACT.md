# 원고 작업판 아티팩트 — 고정 주소

```
https://claude.ai/artifact/BtKcrqzhB4w4mw7JdzD7JT
```

**이 주소는 바뀌면 안 된다.** 원고가 추가되거나 상태가 바뀔 때마다 같은 주소로 갱신한다.

소스: `content/board/manuscript-board.html` (레이아웃·스크립트) + `content/board/posts-data.json`
(원고 데이터 정본 — HTML 안의 `<script id="state">` 에 그대로 주입된다)

## 캘린더와 다른 점: 이 아티팩트는 스스로 저장한다

발행 캘린더는 세션에서만 갱신되지만, 원고 작업판은 `capabilities: {"artifact":{}}` 를 선언해
브라우저에서 상태 버튼(미완료 → 작성중 → 완료)을 누르면 `claude.use("artifact")` 로
**그 자리에서 자기 자신을 재발행**한다.

즉 **저장소의 `posts-data.json` 이 곧 라이브 상태라는 보장이 없다.** 사용자가 브라우저에서 상태를
바꾸면 라이브 아티팩트만 갱신되고, 저장소 파일은 그때 그대로 멈춰 있다.

**그래서 세션에서 이 아티팩트를 갱신하기 전에 반드시 `action: "read"` 로 라이브 버전을 먼저 읽고,
그 안 `<script id="state">` 의 `status` 값을 저장소 값 위에 병합한 뒤 재발행한다.**
저장소 값으로 그대로 덮어쓰면 사용자가 눌러둔 진행 상태가 날아간다.

## 갱신 방법

같은 대화에서라면 같은 파일 경로로 다시 발행하면 주소가 유지된다.

**다른 세션에서 갱신할 때는 반드시 `url` 파라미터에 위 주소를 넘긴다.**
넘기지 않으면 별개의 새 아티팩트가 생기고 주소가 갈린다.

```
Artifact(
  file_path: "content/board/manuscript-board.html",
  url: "https://claude.ai/artifact/BtKcrqzhB4w4mw7JdzD7JT"
)
```

`capabilities` 파라미터는 재발행 시 넘기지 않는다. 넘기면 기존 선언이 사라져 브라우저의
저장 버튼이 죽는다. 필드를 생략하면 현재 설정이 유지된다. `favicon` 도 마찬가지로 넘기지 않는다.

## 새 원고를 추가하거나 상태를 옮길 때

1. `content/posts/<원고>.md` 를 작성하고 `node scripts/lint-post.mjs` 로 통과시킨다.
2. `node scripts/build-post.mjs` 로 `.json` 을 만든다.
3. 위 "라이브 상태 먼저 읽기" 절차대로 board 의 현재 상태 배열을 읽어온다.
4. 새 원고를 카드 하나로 변환해 배열에 추가한다(아래 스키마 참고). 기존 카드의 `status` 는
   라이브에서 읽은 값을 그대로 유지한다.
5. `content/board/posts-data.json` 도 같은 배열로 갱신해 커밋한다 — 저장소가 정본이라는
   원칙(`CLAUDE.md`)을 지키기 위함이다.
6. 위 `url` 로 재발행한다.

## 데이터 스키마

원고 하나 = 배열의 항목 하나.

| 필드 | 내용 |
|---|---|
| `id` | 고유 식별자 (`p1`, `p2`, ...) |
| `status` | `"todo"` 미완료 / `"doing"` 작성중 / `"done"` 작성완료. 브라우저 버튼으로 순환 |
| `title` | 제목. 메인 키워드로 시작 |
| `main` | 메인 키워드 |
| `subs` | 서브 키워드 배열 (2~3개) |
| `vol` | 검색량 (문자열, 천단위 콤마) |
| `chars` | 본문 글자수 — **공백 제외**로 센다 |
| `mainN` | 본문에 메인 키워드가 등장한 횟수 |
| `tags` | 해시태그 없이 쉼표로 구분한 15개 이상 키워드 문자열 |
| `body` | 원고 전문. 아래 인라인 태그를 그대로 담는다 |
| `images` | 이미지 항목 배열 (보통 10장). 각 `{t: 제목, n: 촬영/제작 메모, p: 영문 이미지 생성 프롬프트}` |

`body` 안에서 보드가 인식해 화면 강조·네이버 붙여넣기용 서식으로 바꾸는 태그:

- `[빨간글씨]...[/빨간글씨]`, `[파란글씨]...[/파란글씨]`, `[노란배경]...[/노란배경]`
- `인용구(소제목) 제목 텍스트` — 소제목 한 줄
- `[이미지 N] 설명` — 이미지 삽입 위치 표시

`chars`·`mainN`·키워드 횟수 등 수치는 `CLAUDE.md` 의 분량·키워드 기준(본문 2,300~2,500자,
메인 키워드 10회 이상, 서브 키워드 각 5회 이상)에 맞춰 넣는다. 최종 판정은
`node scripts/lint-post.mjs` 결과를 따른다.
