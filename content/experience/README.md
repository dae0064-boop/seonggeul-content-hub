# 실제 경험 메모 (2026-11-02 사용자 승인)

사용자가 직접 겪은 일(보험 일을 하며 본 상황, 집에서 해 본 살림, 부모님 돌봄 등)을 한두 줄 메모로 주면
Claude 가 `notes.md` 에 한 줄씩 적어 두고, 밤 원고 작업이 주제가 맞는 글에 **1인칭 실화**로 녹여 쓴다.

- 실화로 쓸 수 있는 것은 **이 파일에 적힌 사용자 경험뿐**이다. 그 밖의 장면은 '예를 들면' 장면(가정)으로 쓴다 — CLAUDE.md "장면·경험·대화".
- 메모의 사실을 부풀리거나 숫자를 더하지 않는다. 고객·가족을 알아볼 수 있는 이름·나이·병명 조합은 쓰지 않는다(이 저장소는 공개다).
- 보험 일 경험은 상담·가입 권유로 이어지지 않게 쓴다 (비상업 정보글 규칙 그대로).
- 쓴 글은 메모 줄 끝에 `→ 쓴 글: <날짜 슬러그>` 를 붙인다. 같은 메모는 다른 글에 두 번까지만 쓴다.
- 원고 프런트매터에 `experience: <메모 번호>` 를 적는다 (어느 실화를 썼는지 남긴다).

메모 형식 (`notes.md`):

```
E001 | 2026-11-02 | 살림 | 메모 내용 한두 줄 | → 쓴 글: (없음)
```
