# 네이버 블로그 배너 — ChatGPT 에 붙여 넣을 프롬프트 (2026-11-02 사용자 "촌스럽다, 더 깔끔하게")

ChatGPT(이미지 만들기)에 아래 상자 안 글을 통째로 붙여 넣는다. 결과를 받으면 클라우드 대화가 1920×600 으로 맞추고 위젯 칸 위치·깨진 한글을 고친다.

```
네이버 블로그 상단에 들어갈 가로로 아주 긴 배너 이미지를 만들어 줘. 비율은 가로:세로 = 3.2:1 (최종 1920×600px로 쓸 거야).

[분위기]
- 깔끔하고 정돈된 한국 라이프스타일 매거진 / 무인양품·카페 브랜드 같은 느낌.
- 아이보리·웜화이트 바탕에 여백을 넉넉하게. 포인트 색은 차분한 세이지 그린(#6E8B6B) 하나, 보조색은 연한 베이지(#EFE6DA).
- 테이프, 폴라로이드, 낙서, 점선, 하트·별 같은 장식은 넣지 마. 그림자도 아주 옅게.
- 은은한 자연광 느낌. 촌스럽거나 알록달록하지 않게, 고급스럽고 편안하게.

[배치] (가로 1920 기준 위치)
1. 맨 위 15%는 비워 둬 (네이버 메뉴가 올라가는 자리).
2. 가운데 위쪽(세로 18~48%, 가로 가운데)에 제목:
   - 큰 글씨 "성글벙글" — 둥글고 깔끔한 고딕체, 진한 세이지 그린.
   - 그 아래 작은 글씨 "매일매일 좋은 날을 나누는 공간" — 얇은 고딕체, 회갈색.
   - 제목 뒤에 박스나 종이는 두지 말고 바탕 위에 바로.
3. 아래쪽(세로 55~95%)에 같은 크기의 둥근 모서리 카드 5개를 가로 한 줄로:
   - 카드 하나 가로는 전체의 약 8.9%, 카드 사이 간격 약 0.8%, 첫 카드는 왼쪽에서 25.3% 지점부터 시작 (다섯 개가 가운데보다 아주 살짝 왼쪽).
   - 카드는 흰색, 위쪽 2/3는 사진, 아래 1/3에 글씨.
   - 카드 순서와 사진·글씨:
     ① "생활·정보" — 햇살 드는 깔끔한 세탁실, 개어 둔 흰 수건
     ② "생활·보장" — 정돈된 책상 위 건강수첩·안경·따뜻한 차
     ③ "이슈·뉴스" — 신문과 커피 한 잔
     ④ "연예·방송" — 은은한 조명 아래 마이크
     ⑤ "맛집·나들이" — 창가 테이블의 브런치 한 접시
   - 사진은 모두 같은 톤(밝고 차분한 웜톤, 채도 낮게)으로 통일, 사람 얼굴은 넣지 마.
4. 양옆(가로 0~22%, 78~100%)은 아주 연하게 흐릿한 실내 풍경(창가 커튼, 작은 화분, 나무 선반)만 은은하게 — 가운데 내용보다 눈에 띄지 않게.

[글자]
- 한글 글자는 위에 쓴 그대로 정확하게: 성글벙글 / 매일매일 좋은 날을 나누는 공간 / 생활·정보 / 생활·보장 / 이슈·뉴스 / 연예·방송 / 맛집·나들이
- 그 밖의 글자, 영어, 로고, 워터마크는 넣지 마.
```
