# 네이버 블로그 배너 — 생활보장 블로그판 (2026-11-09 사용자 "생활보장만 남기고 메인도 다시")

ChatGPT(이미지 만들기)에 아래 상자 안 글을 통째로 붙여 넣는다. 틀(제목 위치·카드 5개 위치)은 지금 배너(`chatgpt-prompt.md`)와 같다 — 카드 위 링크 위젯 자리를 그대로 쓰기 위해서다.
결과를 대화에 올리면 클라우드 대화가 1920×600 으로 맞추고 깨진 한글을 고친다.

```
네이버 블로그 상단에 들어갈 가로로 아주 긴 배너 이미지를 만들어 줘. 비율은 가로:세로 = 3.2:1 (최종 1920×600px로 쓸 거야).

[분위기]
- 깔끔하고 믿음이 가는 건강·생활 정보 매거진 느낌. 병원처럼 차갑지 않고 따뜻하게.
- 아이보리·웜화이트 바탕에 여백을 넉넉하게. 포인트 색은 차분한 세이지 그린(#6E8B6B) 하나, 보조색은 연한 베이지(#EFE6DA).
- 테이프, 폴라로이드, 낙서, 점선, 하트·별 같은 장식은 넣지 마. 그림자도 아주 옅게.

[배치] (가로 1920 기준 위치)
1. 맨 위 15%는 비워 둬 (네이버 메뉴가 올라가는 자리).
2. 가운데 위쪽(세로 18~48%, 가로 가운데)에 제목:
   - 큰 글씨 "성글벙글" — 둥글고 깔끔한 고딕체, 진한 세이지 그린.
   - 그 아래 작은 글씨 "병원비·보험금, 혼자 헤매지 않게" — 얇은 고딕체, 회갈색.
   - 제목 뒤에 박스나 종이는 두지 말고 바탕 위에 바로.
3. 아래쪽(세로 55~95%)에 같은 크기의 둥근 모서리 카드 5개를 가로 한 줄로:
   - 카드 하나 가로는 전체의 약 8.9%, 카드 사이 간격 약 0.8%, 첫 카드는 왼쪽에서 25.3% 지점부터 시작.
   - 카드는 흰색, 위쪽 2/3는 사진, 아래 1/3에 글씨.
   - 카드 순서와 사진·글씨:
     ① "실비·보험금" — 나무 책상 위 병원 영수증과 진료비 내역서, 볼펜
     ② "검진·질병" — 건강검진 결과지 봉투와 안경
     ③ "의료비·건강보험" — 계산기와 병원비 고지서
     ④ "돌봄·요양" — 햇살 드는 창가 의자 위 무릎담요와 찻잔
     ⑤ "지원 제도" — 정돈된 서류철과 도장
   - 사진은 모두 같은 톤(밝고 차분한 웜톤, 채도 낮게)으로 통일, 사람 얼굴은 넣지 마. 서류에 읽히는 글자·숫자·회사 이름은 넣지 마.
4. 양옆(가로 0~22%, 78~100%)은 아주 연하게 흐릿한 실내 풍경(창가 커튼, 작은 화분, 나무 선반)만 은은하게.

[글자]
- 한글 글자는 위에 쓴 그대로 정확하게: 성글벙글 / 병원비·보험금, 혼자 헤매지 않게 / 실비·보험금 / 검진·질병 / 의료비·건강보험 / 돌봄·요양 / 지원 제도
- 그 밖의 글자, 영어, 로고, 워터마크, 보험사 이름은 넣지 마.
```
