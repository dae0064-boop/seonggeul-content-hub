0. `routines/README.md` 의 "공통 시작"을 먼저 한다. 그날 아침 PC 실행 결과(Drive `ClaudeWorkspace/run-logs` 의
   day-<날짜>-tistory.log)가 있으면 읽고, 예약이 '임시저장만 (예약 확인 실패)'였다면 로그의 '예약 칸' 줄을 근거로
   scripts/publish-tistory.mjs 의 reservePublish 를 고쳐 같은 PR 에 넣는다.
1. 다시 읽는다: CLAUDE.md, memory/CLAUDE.md, docs/TISTORY.md, standards/이미지-기준.md, standards/image-style.json.
   형식 견본은 가장 최근 content/tistory/*.md 와 그 이미지 계획서 content/image-plans/<같은 슬러그>.json.
   **티스토리 자동 원고는 2026-10-05(월) 원고부터 쓴다** (2026-10-03 사용자 지시). 내일이 2026-10-04 이면 쓰지 않고 끝낸다.
2. main 에 내일 날짜 content/tistory/<날짜>-*.md 가 이미 5개 있으면 lint-tistory 만 돌리고 끝낸다.
3. 짝이 되는 네이버 글: main 의 content/posts/<내일 날짜>-*.md 5편(20:53 네이버 작업이 올린다). 아직 없으면
   content/calendar/publish-calendar.html 의 `const W=[...]` 에서 내일 날짜 t 5개를 네이버 글감으로 본다.
   네이버 글 하나당 티스토리 1편, 같은 묶음(클러스터) 안에서 다른 메인 키워드·다른 질문으로 쓴다
   (예: 네이버 '텐트 결로' → 티스토리 '침낭 고르는 법'). 네이버 글을 고쳐 쓰지 않는다 — 같으면 유사문서에 걸린다.
   source_post 에 짝 네이버 글 슬러그를 적는다.
4. 키워드: CLAUDE.md "분량과 키워드" 대로 직접 고른다. content/calendar/title-keywords/ 결과를 먼저 보고, 없으면 WebSearch 로
   그 말을 제목에 쓴 글이 해마다 이맘때 꾸준히 올라오는지·연관 질문이 많은지·공식 기관이 상단을 차지하지 않는지 본다.
   검색 수요가 바닥인 말과 그날만 찾는 날짜형 글감은 쓰지 않는다. 티스토리는 구글 검색으로 들어오므로
   "~하는 법", "~차이", "~고르는 법"처럼 질문에 바로 답하는 말을 우선한다. 사용자에게 키워드 조회를 부탁하지 않는다.
5. 원고 5편 content/tistory/<내일 날짜>-<슬러그>.md — 서식·말투·인사말은 네이버 원고와 같다(2026-10-02 사용자 지시):
   해요체, 고정 여는 인사, 의미 단위 줄바꿈(줄 30자 이하), 덩어리 2~4줄, 소제목 바로 아래 덩어리 3줄 이하, 인용구(소제목) 7~9개(9개 넘으면 검사기 불통과 — 2026-10-03 사용자 지시),
   빨강 3~5·파랑 6~10·노랑 배경 3~5, 공백 제외 2,100~2,300자, 메인 10회·서브 각 5회, 제목은 메인 키워드로 시작 + 서브 1~2개
   (비율 50~60%), Q&A 3쌍(또는 CLAUDE.md "글 모양 돌려 쓰기"의 format), 이미지 8자리(2~8번은 소제목 바로 아래 — 소제목 → 그림 → 글), 출처 문단, 주제 태그 15개.
   다른 점: 닫는 인사 첫 줄은 "좋아요·공감과 구독 부탁드려요💙", 고정 태그(서이추·이웃추가·서이추환영)는 붙이지 않는다.
   publish_at 은 짝 네이버 글 시각 + 30분 (11:30·13:30·15:30·17:30·19:30, 2026-10-03 사용자 지시).
   1인칭 경험담 지어내기 금지, 확인 못 한 수치·제도·기관명 금지(공공기관 사이트는 막혀 있으니 WebSearch 로 교차 확인),
   건강·금융·법률은 전문가 상담 안내. 보험 글은 CLAUDE.md 의 비상업 정보글 규칙을 지킨다.
