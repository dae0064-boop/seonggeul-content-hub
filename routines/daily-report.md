# 하루 작업 정리 (매일 00:53)

2026-11-13 사용자: "창을 굳이 여러 개 만들지 말고, 오늘 네이버·티스토리·철거·스레드·인스타 업무를 다 했으면
창을 하나 만들어서 오늘 작업한 내용은 이렇고, 다 했다고 이야기만 해 줘."

자동 작업(Routine)은 회차마다 새 작업 대화를 만든다(구조는 `routines/README.md`). 그 대화들이 사용자 목록에 쌓이지 않도록
**이 대화가 하루치를 모아 한 번 보고하고, 끝난 작업 대화는 보관(archive)해 목록에서 치운다.** 사용자가 보는 창은 이 대화 하나다.

## 1. 모을 대상

`mcp__claude-code-remote__list_sessions`(`mine: true`, 필요하면 `after_id` 로 넘겨 보기)에서 아래를 모두 고른다.

- `parent_session_id` 가 `session_01WUegR24cgu6FcuB28zoaSk`(⚙ 자동 작업 출발점)인 대화 중 **보관되지 않은 것** — 네이버 원고(1~4차)·티스토리 원고(1·2차, 인스타 포함)·철거 원고(1·2차)·이슈 글·아침 확인·캘린더·일회성 작업.
- 제목이 `⚡ 스레드 일상 글` 로 시작하는 대화(19:47 Routine 이 따로 만든다).
- 이전 날의 `하루 작업 정리` 대화(이 파일로 만든 것) — 보고 대상은 아니고 4번에서 보관만 한다.
- **출발점 대화(`session_01WUegR24cgu6FcuB28zoaSk`)와 지금 이 대화는 절대 보관하지 않는다.** 사람이 직접 연 대화(origin `desktop_app`·`android` 등, 부모 없음)도 건드리지 않는다.

## 2. 아직 도는 대화가 있으면 기다린다

`status_bucket` 이 `WORKING`(또는 `BLOCKED`)인 대화가 있으면 보고하지 않고 `send_later` 로 20분 뒤 이 대화에 "다시 1번부터"를 건다.
02:30 이 지나도 도는 대화는 "아직 진행 중"으로 적고 보고한다(보관하지 않는다).

## 3. 결과 확인 — 대화 요약만 믿지 않는다

1. `git fetch origin main` 후 main 에서 확인한다.
   - 네이버: `content/posts/<내일>-*.md` 편수와 `node scripts/lint-post.mjs` 통과 수 (목표 편수는 `routines/naver-daily.md` 기준).
   - 티스토리: `content/tistory/<내일>-*.md` 편수, `node scripts/lint-tistory.mjs` 통과 수.
   - 철거: `content/chulgeo/posts/<내일>-*` 편수, `node scripts/chulgeo/lint.mjs` 통과 수.
   - 스레드: `content/threads/daily/<내일>.md`·`content/threads/blog/<내일>.md` 있는지, 보험 심의글 15:00 차례(STATUS 기준).
   - 인스타: 오늘 밤 원고를 썼는지 / 멈춤 지시로 건너뛰었는지(티스토리 원고 대화 요약·`routines/instagram-daily.md` 맨 위).
2. 각 작업 대화의 마지막 보고(`post_turn_summary`, 모자라면 `list_events` 의 마지막 assistant 메시지)에서 **사용자 확인이 필요하다고 한 것**을 모은다.
3. 오늘 아침 확인(10:47) 대화의 핵심(예약 결과·조회수·고친 것)은 두세 줄로 옮긴다.

## 4. 보관

`status_bucket` 이 `COMPLETED`·`REVIEW_READY` 인 1번 대화를 `mcp__claude-code-remote__archive_session` 으로 보관한다.
`FAILED` 이거나 아직 도는 대화는 보관하지 않고 보고에 "남겨 둔 대화: <제목>"으로 적는다 — 사용자가 열어 볼 수 있게.
보관 도구가 없으면 보관은 건너뛰고 보고 맨 끝에 한 줄로 알린다.


- 커밋할 것이 없으면 커밋·PR 하지 않는다. `docs/STATUS.md` 는 고치지 않는다(각 작업 대화가 이미 적는다).
