   아직 저장소에 없으면 `content/calendar/title-keywords/<그 날짜>-queue.txt` 로 그대로 옮긴다.
   조회된 키워드는 content/calendar/keyword-queue.txt 에서 지운다.
3. **일요일 처리 (2026-10-03 사용자 결정 — 일요일은 자율, PC 를 켤 수도 안 켤 수도 있다)**:

   - 내일이 일요일이면: 캘린더에 일요일 항목이 없어도 일요일 원고 5편을 쓴다 — 캘린더 뒷날 글감을 당겨 오거나
     (당긴 날은 캘린더에서 비우고 새 글감으로 채움) 매년 이맘때 검색되는 새 살림 글감으로. 일요일 항목을 캘린더 소스에 추가한다.
4. 글감: content/calendar/publish-calendar.html 의 `const W=[...]` 에서 내일 날짜(d)의 t 를 순서대로 5개.
   main 에 내일 날짜 원고가 이미 5개 있으면 검사기만 돌린다. 5편 = 살림·생활 노하우 4 + 생활보장(보험) 1.
   보험 글감이 없으면 가장 약한 글감 하나를 생활과 이어지는 보험 글감으로, 둘 이상이면 하나만 남긴다.
   가 보지 않은 맛집·장소(명소·휴게소) 글은 되도록 살림 노하우 글감으로 바꾼다.
   검색이 약한 말(검색량 자료 100 미만)·하루만 찾는 말은 같은 달 다른 글감이나 더 검색이 붙는 말로 바꾸고 캘린더에도 반영한다.
   아침 확인 작업이 통계로 바꿔 둔 캘린더·STATUS 내용을 따른다.
5. 다음 후보 채우기: 모레·글피(2~3일치, 일요일 포함) 글감마다 메인 키워드 후보 2~3개를 content/calendar/keyword-queue.txt 에
   날짜 주석과 함께 넣는다. 이미 title-keywords 자료에 있는 말은 넣지 않는다.
6. 키워드: title-keywords 자료가 있으면 그 숫자로 고른다 — 메인은 월 1,000~10,000 우선, 100 미만 금지(검사기가 막음),
   30,000 넘는 큰 말은 서브로만. 자료가 없으면 WebSearch 로 판단한다. 사용자에게 조회를 부탁하지 않는다.
7. 원고 5편 content/posts/<날짜>-<슬러그>.md: publish_at 은 순서대로 10:00, 10:50, 11:40, 14:00, 16:00 (오전 3·오후 2, 2026-10-03 밤 사용자 지시 — 저녁 늦은 글은 노출이 약하다).

   format 은 같은 날 같은 모양 2편까지·3가지 이상.
   보험 글은 심의가 필요 없는 비상업 정보글만 — 상담·연락·가입·해지 권유, 보험사·상품 이름, 보험료 금액,
   설계사 신분·연락처 금지, 끝은 "내 증권·약관에서 확인해 보세요" 식. [4] 광고 심의 셀프체크 적용.
   제목은 메인 키워드로 시작 + 서브 1~2개(비율 50~60%, 40자 안쪽). 본문 공백 제외 2,100~2,300자(처음부터 2,300자 목표로 길게),
   줄 30자 이하, 덩어리 2~4줄, 소제목 바로 아래 3줄 이하, 강조 빨강 3~5·파랑 6~10·노랑 3~5, 이미지 8자리(2~8번은 소제목 바로 아래 — 소제목 → 그림 → 글, 소제목 7~9개), 고정 인사말,
   출처 줄 ①/②(확인 안 한 기관명 금지), 태그 주제 15개 + 서이추, 이웃추가, 서이추환영.
   1인칭 경험담 금지. 확인 못 한 수치·제도는 쓰지 않는다. 건강·금융은 전문가 상담 안내(우리에게 상담하라는 말은 금지).
