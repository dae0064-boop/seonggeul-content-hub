   형식 견본은 content/threads/insurance/sets/ 의 가장 최근 파일.
2. 오늘(Asia/Seoul) 날짜를 W 라 한다. sets/*.md 중 프런트매터 `written: W` 인 묶음이 main 에 이미 있으면
   검사기만 돌리고 짧게 알린 뒤 끝낸다.
3. 새 파일 이름: sets/ 에서 이름순 마지막 파일의 날짜 + 1일 (Word 번호가 파일 이름 순서로 매겨지므로 앞에 끼워 넣지 않는다).
   프런트매터: `date: <그 날짜>`, `written: W`, `심의필:`(비움).
4. 글감 10개: content/threads/insurance/topics.txt 의 안 쓴 줄(`# 사용`·`# 겹침` 표시 없는 줄)에서 고른다.
   역할 5칸(오해풀기·숨은권리·증권한줄·생활장면·마음이야기)을 두 번씩, 보험 종류 10개는 모두 다르게.
   지금 계절·다가오는 시기에 맞는 생활장면을 먼저 정한다. 모자라면 같은 형식으로 topics.txt 에 새 글감을 보태 쓴다.
   **쓰기 전에 지난 묶음 전체의 글감과 첫 줄을 훑어, 말은 달라도 같은 증권 칸·같은 조언이면 다른 글감으로 바꾼다**
   (검사기는 낱말 겹침만 잡는다 — 2026-10-03 사용자 지시). 쓴 줄 앞에 `# 사용 <파일 날짜> ` 를 붙인다.
5. 10편을 rules.md 양식으로 쓴다: 300자·19줄·한 줄 24자 이하 — 짧은 글감은 200자 안팎으로 짧게, 설명이 필요한 글감은
   "상품마다 달라요"로 뭉뚱그리지 말고 확인한 사실 한두 줄을 채워 300자까지 (2026-10-03 사용자 지시).
   첫 줄 = 독자가 묻는 질문 + 이모지, 둘째 줄 “따옴표 속 말”, 빈 줄·해시태그 없음, `~해요`/`~더라구요` 중심(`~입니다` 한 번 이하),
   말끝에 !·…·~ 를 2~3번, 마지막 줄은 "확인해 보세요/봐 주세요" 같은 점검형 권유,
   이모지 2~3개 (노란 하트 💛 금지, 돈 이모지 💰💵💸🤑·₩$ 금지).
   "궁금한 건 친근한 설계사에게 물어보세요" 는 문맥이 맞는 글에만 묶음당 3편까지 (10/11 까지 이대로, 그 뒤 사용자와 다시 정한다).
   가입·해지 권유, 일 단위 보험료, 타사 비교, 상담 유도("연락주세요"·DM 포함), 공포 표현, 무조건·100%·최고 같은 단정 금지.
   실손(실제 치료비)과 정액(진단비 등)을 섞어 말하지 않는다.
6. 사실 확인: 숫자·기간·제도, 그리고 예외·조건 예시까지 WebSearch 로 정부·금융당국·보험협회·법령 1차 자료를 찾아
   `출처:` 에 기관·자료명·URL 을 적는다. 찾지 못한 것은 쓰지 않는다(숫자 없이 쓰거나 다른 글감으로).
